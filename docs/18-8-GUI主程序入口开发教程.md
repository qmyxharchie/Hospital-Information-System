## 1. 模块概述

### 1.1 功能描述

GUI主程序入口模块（main_gui.cpp）负责整个医院信息管理系统的图形界面启动和流程控制，包括GUI系统初始化、用户登录界面、主功能界面、事件处理和界面导航等功能。

### 1.2 GUI主程序与其他模块的关系

```
┌─────────────────────────────────────────────────────┐
│          main_gui.cpp (GUI主程序入口)              │
│  - GUI系统初始化                                  │
│  - 用户登录界面                                   │
│  - 主功能界面                                     │
│  - 事件处理机制                                   │
│  - 界面导航控制                                   │
└─────────────────────────────────────────────────────┬─
                   │ 调用各模块函数
                   │
┌─────────────────────────────────────────────────────┬─
│              各业务模块 (patient.c、doctor.c等)       │
│  - 实现具体业务逻辑                                │
│  - 提供函数接口                                    │
└─────────────────────────────────────────────────────┬─
                   │ 调用文件读写函数
                   │
┌─────────────────────────────────────────────────────┐
│              数据持久化 (file_io.c)                │
│  - 从 data/*.txt 读入链表                          │
│  - 从链表写入 data/*.txt                           │

```

### 4.2 WinMain函数实现思路

```cpp
// WinMain函数示例格式
int WINAPI WinMain(HINSTANCE hInstance, HINSTANCE hPrevInstance, 
                   LPSTR lpCmdLine, int nCmdShow) {
    // 初始化GUI系统
    if (!initGuiSystem()) {
        MessageBox(NULL, L"系统初始化失败！", L"错误", MB_OK | MB_ICONERROR);
        return -1;
    }
    
    // 创建主窗口
    mainWindow = make_unique<Window>(WINDOW_WIDTH, WINDOW_HEIGHT, L"医院信息管理系统");
    
    // 创建登录界面
    createLoginInterface();
    
    // 创建主功能界面
    createMainInterface();
    
    // 默认显示登录界面
    loginCanvas->setIsVisible(true);
    mainCanvas->setIsVisible(false);
    
    // 绘制界面
    mainWindow->draw();
    
    // 启动事件循环
    runEventLoop();
    
    // 程序退出时保存数据
    exitGuiSystem();
    
    return 0;
}
```

**实现提示**：
- 使用WinMain而非main函数
- 确保资源正确释放
- 程序退出时保存数据

```cpp
// 事件绑定函数示例格式
void bindLoginEvents(void) {
    // 绑定用户登录按钮事件
    loginButton->setOnClickListener([&]() {
        // 获取用户输入
        wstring username = usernameBox->getText();
        wstring password = passwordBox->getText();
        
        // 验证输入
        if (username.empty() || password.empty()) {
            MessageBox::showModal(L"用户名和密码不能为空！");
            return;
        }
        
        // 转换为ANSI字符串进行验证
        char usernameAnsi[50], passwordAnsi[50];
        wcstombs(usernameAnsi, username.c_str(), sizeof(usernameAnsi));
        wcstombs(passwordAnsi, password.c_str(), sizeof(passwordAnsi));
        
        // 验证登录
        if (verifyLogin(usernameAnsi, passwordAnsi, false)) {
            // 登录成功，切换到主界面
            loginCanvas->setIsVisible(false);
            mainCanvas->setIsVisible(true);
            
            // 更新状态信息
            MessageBox::showModal(L"登录成功！");
        } else {
            // 登录失败
            MessageBox::showModal(L"用户名或密码错误！");
        }
    });
    
    // 绑定管理员登录按钮事件
    adminButton->setOnClickListener([&]() {
        // 获取用户输入
        wstring username = usernameBox->getText();
        wstring password = passwordBox->getText();
        
        // 验证输入
        if (username.empty() || password.empty()) {
            MessageBox::showModal(L"用户名和密码不能为空！");
            return;
        }
        
        // 转换为ANSI字符串进行验证
        char usernameAnsi[50], passwordAnsi[50];
        wcstombs(usernameAnsi, username.c_str(), sizeof(usernameAnsi));
        wcstombs(passwordAnsi, password.c_str(), sizeof(passwordAnsi));
        
        // 验证管理员登录
        if (verifyLogin(usernameAnsi, passwordAnsi, true)) {
            // 管理员登录成功，切换到主界面
            loginCanvas->setIsVisible(false);
            mainCanvas->setIsVisible(true);
            
            // 更新状态信息
            MessageBox::showModal(L"管理员登录成功！");
        } else {
            // 登录失败
            MessageBox::showModal(L"用户名或密码错误，或非管理员账户！");
        }
    });
}
```

**实现提示**：
- 事件处理要安全验证输入
- 字符串转换要注意编码
- 界面切换要平滑自然
