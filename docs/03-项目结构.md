## 2. 文件详细说明

### 2.1 构建配置

| 文件 | 说明 |
|------|------|
| `CMakeLists.txt` | CMake构建配置，定义项目名称、编译器、源文件等 |

### 2.2 核心业务模块

| 文件 | 说明 | 需要实现的函数 |
|------|------|---------------|
| `patient.c/h` | 病人信息管理 | addPatient, delPatient, modifyPatient, findPatientByCardNo, listAllPatients |
| `doctor.c/h` | 医生信息管理 | addDoctor, delDoctor, modifyDoctor, findDoctorByEmpNo, listAllDoctors |
| `registration.c/h` | 挂号记录管理 | addRegistration, cancelRegistration, completeRegistration, listAllRegistrations |
| `medicine.c/h` | 药品库存管理 | addMedicine, delMedicine, modifyMedicine, purchaseMedicine, checkLowStock |
| `hospitalization.c/h` | 住院记录管理 | addHospitalization, dischargePatient, listAllHospitalizations |
| `bed.c/h` | 床位信息管理 | addBed, allocateBed, freeBed, listAllBeds |

### 2.3 系统模块

| 文件 | 说明 | 需要实现的函数 |
|------|------|---------------|
| `login.c/h` | 登录系统 | login, registerUser, buildUserChain |
| `file_io.c/h` | 文件读写 | rebuildXxxFile, buildXxxChain（每个数据模块一套） |
| `utils.c/h` | 工具函数 | generateUniqueId, getCurrentTime, safeStringCopy, isValidPhone, isValidIdCard, trim |
| `ui.c/h` | 控制台界面 | showMainMenu, showPatientManagement, showDoctorManagement 等 |

### 2.4 GUI模块

| 文件 | 说明 |
|------|------|
| `main_gui.cpp` | GUI主程序入口，WinMain函数 |
| `StellarX/*` | 图形界面库（可直接使用） |

## 3. 数据文件格式

### 3.1 patient.txt

```
1                           ← 有效记录标记
PT20260407142530           ← 门诊卡号
张三                        ← 姓名
男                          ← 性别
220102199001011234          ← 身份证
13800138000                 ← 电话
0                           ← 住院状态（0=否，1=是）
                             ← 空行分隔
-1                          ← 文件结束标记
```

### 3.2 doctor.txt

```
1
DOC001                      ← 工号
刘医生                      ← 姓名
内科                        ← 科室
周一、周三、周五             ← 出诊时间
30                         ← 每日最大接诊数
0                          ← 今日已接诊数
-1
```

### 3.3 medicine.txt

```
1
MED001                      ← 药品编号
阿莫西林                    ← 通用名
阿莫西林胶囊                 ← 商品名
0.5g*24粒                   ← 规格
15.50                       ← 单价
150                         ← 当前库存
20                          ← 最低库存预警值
-1
```

### 3.4 bed.txt

```
1
内科                        ← 病区
B101                        ← 床位号
空                          ← 病人卡号（空=无病人）
空                          ← 病人姓名
空闲                        ← 状态（空闲/占用/维修）
-1
```

### 3.5 user.txt

```
1
admin                       ← 用户名
21232f297a57a5a743894a0e4a801fc3  ← 密码（MD5加密后的"admin"）
1                           ← 角色（0=用户，1=管理员）
2026-04-07                  ← 最后登录时间
-1
```

