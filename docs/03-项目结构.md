## 2. 文件详细说明

### 2.1 构建配置文件

| 文件 | 说明 |
|------|------|
| `CMakeLists.txt` | CMake构建配置，定义项目名称、编译器、源文件等 |

### 2.2 核心业务模块

| 文件 | 说明 | 主要函数 |
|------|------|----------|
| `patient.c/h` | 病人信息管理 | addPatient, delPatient, findPatientByCardNo, listAllPatients |
| `doctor.c/h` | 医生信息管理 | addDoctor, delDoctor, findDoctorByEmpNo, listAllDoctors |
| `registration.c/h` | 挂号记录管理 | addRegistration, cancelRegistration, completeRegistration |
| `medicine.c/h` | 药品库存管理 | addMedicine, delMedicine, replenishStock, checkLowStock |
| `hospitalization.c/h` | 住院记录管理 | addHospitalization, dischargePatient |
| `bed.c/h` | 床位信息管理 | addBed, allocateBed, freeBed |

### 2.3 系统模块

| 文件 | 说明 | 主要函数 |
|------|------|----------|
| `login.c/h` | 登录系统 | login, registerUser, buildUserChain |
| `file_io.c/h` | 文件读写 | rebuildXxxFile, buildXxxChain |
| `utils.c/h` | 工具函数 | generateUniqueId, getCurrentTime, safeStringCopy |
| `ui.c/h` | 控制台界面 | showMainMenu, showPatientManagement 等 |

### 2.4 GUI模块

| 文件 | 说明 |
|------|------|
| `main_gui.cpp` | GUI主程序入口 |
| `StellarX/*` | 图形界面库 |

## 3. 数据文件格式

### 3.1 patient.txt（病人数据）

```
1                                    ← 1=有效，-1=结束
PT20260407142530                    ← 门诊卡号
张三                                 ← 姓名
男                                   ← 性别
220102199001011234                   ← 身份证
13800138000                          ← 联系电话
0                                    ← 住院状态（0=否，1=是）

1
PT20260407142531
李四
女
220102199002022345
13800138001
0

-1                                   ← 文件结束
```

### 3.2 doctor.txt（医生数据）

```
1
DOC001                               ← 工号
刘医生                               ← 姓名
内科                                 ← 科室
周一、周三、周五                      ← 出诊时间
30                                   ← 每日最大接诊数
0                                    ← 今日已接诊数

-1
```

### 3.3 medicine.txt（药品数据）

```
1
MED001                               ← 药品编号
阿莫西林                             ← 通用名
阿莫西林胶囊                          ← 商品名
0.5g*24粒                            ← 规格
15.50                                ← 单价
150                                  ← 当前库存
20                                   ← 最低库存预警值

-1
```

### 3.4 bed.txt（床位数据）

```
1
内科                                 ← 病区
B101                                 ← 床位号
PT003                                ← 病人卡号（空=无病人）
王五                                 ← 病人姓名
占用                                 ← 状态

-1
```

### 3.5 user.txt（用户数据）

```
1
admin                                ← 用户名
21232f297a57a5a743894a0e4a801fc3    ← 密码（MD5加密）
1                                    ← 角色（0=用户，1=管理员）
2026-04-07                          ← 最后登录时间

-1
```

## 5. 创建项目目录结构

### 5.1 手动创建

```powershell
# 在项目根目录执行
mkdir include
mkdir src
mkdir data
mkdir backup
mkdir bin
mkdir docs
mkdir image
mkdir "include/StellarX"
mkdir "src/StellarX"
```

### 5.2 Windows命令行创建

```cmd
cd /d D:\hospital-management
mkdir include src data backup bin docs image
mkdir include\StellarX src\StellarX
```
