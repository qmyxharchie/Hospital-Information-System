## 1. 模块概述

### 1.1 功能描述

登录模块负责用户身份验证：
- 用户登录
- 管理员登录
- 用户注册
- 密码加密存储

### 1.2 安全特性

**MD5密码加密**：
- 密码不以明文存储
- 相同密码产生相同哈希值
- 不可逆向解密

## 2. 数据结构

```c
// login.h
typedef struct User {
    char username[50];           // 用户名
    char password[100];          // 密码（MD5哈希）
    int role;                    // 角色（0=用户，1=管理员）

typedef enum {

    LOGIN_SUCCESS_USER = 1,
    LOGIN_SUCCESS_ADMIN = 2,
    LOGIN_EXIT = 3
} LoginStatus;
```

## 3. MD5加密原理

### 3.1 什么是MD5？

MD5（Message-Digest Algorithm 5）是一种常用的哈希函数：
- 输入任意长度内容
- 输出128位（16字节）哈希值
- 相同输入产生相同输出
- 不可反向还原原内容

### 3.2 MD5示例

```
输入: "admin"
MD5:  "21232f297a57a5a743894a0e4a801fc3"

输入: "123456"
MD5:  "e10adc3949ba59abbe56e057f20f883e"
```

### 3.3 简单MD5实现

```c
void md5Hash(const char* input, char* output) {
    // 简化版：实际项目应使用成熟MD5库
    unsigned int hash = 5381;
    int c;
    while ((c = *input++)) {
        hash = ((hash << 5) + hash) + c;
    }
    sprintf(output, "%08x", hash);
}
```

## 4. 核心函数

### 4.1 用户登录

```c
LoginStatus login(char username[], char password[]) {
    User* head = NULL, * tail = NULL;
    buildUserChain(&head, &tail);
    
    // 生成密码哈希
    char pwdHash[100];
    md5Hash(password, pwdHash);
    
    // 遍历查找用户
    User* p = head;
    while (p != NULL) {
        if (strcmp(p->username, username) == 0) {
            if (strcmp(p->password, pwdHash) == 0) {
                strcpy(g_currentUsername, username);
                g_currentUserRole = p->role;
                g_isLoggedIn = true;
                return (p->role == 1) ? LOGIN_SUCCESS_ADMIN : LOGIN_SUCCESS_USER;
            }
        }
        p = p->next;
    }
    
    freeUserChain(head);
    return LOGIN_FAILED;
}
```

### 4.2 用户注册

```c
bool registerUser(char username[], char password[], int role) {
    User* head = NULL, * tail = NULL;
    buildUserChain(&head, &tail);
    
    // 检查是否已存在
    User* p = head;
    while (p != NULL) {
        if (strcmp(p->username, username) == 0) {
            printf("[ERROR] 用户名已存在！\n");
            freeUserChain(head);
            return false;
        }
        p = p->next;
    }
    
    // 创建新用户
    User* now = (User*)malloc(sizeof(User));
    safeStringCopy(now->username, username, 50);
    md5Hash(password, now->password);
    now->role = role;
    getCurrentTime(now->lastLogin, 30);
    
    // 插入链表
    if (head == NULL) {
        head = tail = now;
    } else {
        tail->next = now;
        now->pre = tail;
        tail = now;
    }
    
    rebuildUserFile(head);
    freeUserChain(head);
    
    printf("[INFO] 注册成功！\n");
    return true;
}
```
