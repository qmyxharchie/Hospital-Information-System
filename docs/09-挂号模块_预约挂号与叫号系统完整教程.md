# 挂号模块 - 预约挂号与现场挂号混合模式完整教程

> 本文档基于 `docs/09-挂号模块_.md` 和现有 `registration.c/h` 代码进行重构升级，新增**预约挂号**、**候诊队列**、**医生叫号**三大核心功能，实现挂号业务全流程闭环。
>
> **配套修改**：涉及 `registration.c/h` 核心函数重写、`patient.c`（患者自助查询/取消）、`doctor.c`（医生叫号/候诊列表）、`ui.c`（菜单界面）四个模块。

---

## 1. 模块概述

### 1.1 业务背景

随着周边新建小区陆续建成并投入使用，区域内常驻人口持续增长，门诊就诊患者数量显著增加。原有系统仅支持就诊当日**现场挂号**一种模式，已无法应对日益增长的就诊需求。该模式易造成患者在挂号窗口、候诊大厅大量聚集，不仅显著延长患者排队与等候时间，降低就医体验，同时也扰乱正常就诊秩序，存在一定的院内安全与卫生隐患。

### 1.2 解决方案

实施**预约挂号 + 现场挂号**相结合的混合模式：

| 挂号方式 | 操作人 | 适用场景 | 号源管理 |
|---------|--------|---------|---------|
| **预约挂号** | 患者（线上/自助机） | 提前 1~7 天预约指定医生和时段 | 占用医生每日最大接诊数 |
| **现场挂号** | 护士（挂号窗口） | 当日到院即时挂号 | 占用医生每日最大接诊数 |

**就诊流程**：

```
患者预约挂号/现场挂号 → 系统生成候诊队列 → 医生叫号 → 患者就诊 → 标记完成
     ↑                                                              |
     └────────────── 患者可自助取消（仅限待就诊状态） ←────────────┘
```

### 1.3 挂号状态流转

```
                    ┌────────── 取消挂号 ──────────┐
                    ↓                              │
  【挂号成功】──→ PENDING(待就诊) ──→ IN_PROGRESS(就诊中) ──→ COMPLETED(已完成)
                    │                                    ↑
                    └────────── 医生叫号 ────────────────┘
```

- **PENDING（待就诊）**：挂号成功后的初始状态，患者在候诊队列中等待
- **IN_PROGRESS（就诊中）**：医生叫号后，患者进入诊室就诊
- **COMPLETED（已完成）**：医生完成诊疗，标记就诊结束
- **CANCELLED（已取消）**：患者取消挂号或护士撤销挂号，释放号源

### 1.4 功能清单

| 功能 | 操作角色 | 对应函数 |
|------|---------|---------|
| 预约挂号 | 患者 | `patientAppointmentRegistration()` |
| 现场挂号 | 护士 | `nurseOnsiteRegistration()` |
| 取消挂号 | 患者/护士 | `patientCancelRegistration()` / `cancelRegistration()` |
| 医生叫号 | 医生 | `callNextPatient()` |
| 完成就诊 | 医生 | `completeRegistration()` |
| 查看候诊队列 | 医生/护士 | `buildWaitingQueue()` + `listWaitingQueue()` |
| 查看个人挂号 | 患者 | `patientViewOwnRegistrations()` |
| 科室挂号统计 | 护士 | `nurseViewDepartmentRegistrations()` |

## 2. 数据结构（registration.h）

现有 `registration.h` 已定义了较完整的结构体，**无需修改结构体定义**，只需确保各字段正确填充和使用。

### 2.1 挂号状态枚举

```c
// registration.h

typedef enum {
    PENDING = 0,      // 待就诊 — 挂号成功后在候诊队列中等待
    IN_PROGRESS = 1,  // 就诊中 — 医生叫号后患者进入诊室
    COMPLETED = 2,    // 已完成 — 医生完成诊疗
    CANCELLED = 3     // 已取消 — 患者取消或护士撤销
} RegStatus;
```

### 2.2 挂号记录结构体

```c
// registration.h（已有定义，确认字段用途）

typedef struct RegistrationData {
    char regNo[20];              // 挂号单号（自动生成，如"REG001"）
    char patientCardNo[20];      // 病人卡号
    char patientName[50];        // 病人姓名（冗余存储，便于直接显示）
    char doctorEmpNo[20];        // 医生工号
    char doctorName[50];         // 医生姓名（冗余存储）
    char dept[50];               // 科室
    char date[20];               // 挂号日期（格式：YYYY-MM-DD，系统当前日期）
    char time[20];               // 挂号时间（格式：HH:MM:SS，系统当前时间）
    char appointmentDate[20];    // 预约日期（预约挂号=患者指定日期；现场挂号=当天日期）
    char appointmentTime[20];    // 预约时间（预约挂号=患者指定时段；现场挂号=当前时间）
    RegStatus status;            // 挂号状态（PENDING/IN_PROGRESS/COMPLETED/CANCELLED）
    UserRole createdBy;          // 挂号方式（PATIENT=患者预约挂号，NURSE=护士现场挂号）
    float consultationFee;       // 诊疗费用（预留字段，可先填0）
    char remarks[100];           // 备注信息（预留字段）

```

> **字段说明**：
> - `date`/`time`：系统**自动生成的实际挂号时间**，用于记录操作日志
> - `appointmentDate`/`appointmentTime`：患者**期望的就诊日期和时段**，用于候诊队列排序
> - `createdBy`：区分挂号渠道（患者自助预约 vs 护士窗口挂号），用于权限追溯

## 3. registration.c 核心函数实现

### 3.1 重写 addRegistration() — 支持预约挂号

**现有问题**：当前 `addRegistration()` 接收了 `appointmentDate`、`appointmentTime`、`createdBy` 三个参数，但函数体**完全没有使用**，所有挂号都当作当天现场挂号处理。

**改造目标**：
1. 正确填充 `appointmentDate`、`appointmentTime`、`createdBy` 字段
2. 区分预约挂号和现场挂号的提示信息
3. 当天挂号才增加医生 `currentPatients`（当天占号），非当天预约暂不占用
4. 增加重复挂号检查（同一天同一医生同一患者不能挂两次）

**完整实现**：

```c
//-------------------------
// 添加挂号记录（支持预约挂号 + 现场挂号）
// 参数：
//   appointmentDate — 预约日期（YYYY-MM-DD），现场挂号时传当天日期
//   appointmentTime — 预约时间（HH:MM），现场挂号时传当前时间
//   createdBy — PATIENT（患者预约）或 NURSE（护士现场挂号）
// 返回值：1=成功，0=失败
//-------------------------
int addRegistration(Registration** head, Registration** tail,
    char* patientCardNo, char* patientName,
    char* doctorEmpNo, char* doctorName, char* dept,
    char* appointmentDate, char* appointmentTime, UserRole createdBy)
{
    // 1. 验证医生是否存在
    Doctor* d = findDoctorByEmpNo(g_doctorHead, doctorEmpNo);
    if (d == NULL) {
        printf("[ERROR] 未找到工号为 %s 的医生\n", doctorEmpNo);
        return 0;
    }

    // 2. 检查医生是否还有名额（仅对当天挂号进行号源检查）
    int year, month, day;
    getCurrentTime(&year, &month, &day);
    char today[20];
    sprintf(today, "%04d-%02d-%02d", year, month, day);

    if (strcmp(appointmentDate, today) == 0) {
        if (!canAcceptPatient(d)) {
            printf("[ERROR] 该医生今日号源已满（最大接诊 %d 人）\n", d->data.maxPatients);
            return 0;
        }
    }

    // 3. 重复挂号检查：同患者同一天同医生不能重复挂 PENDING 状态
    Registration* temp = *head;
    while (temp != NULL) {
        if (strcmp(temp->data.patientCardNo, patientCardNo) == 0 &&
            strcmp(temp->data.doctorEmpNo, doctorEmpNo) == 0 &&
            strcmp(temp->data.appointmentDate, appointmentDate) == 0 &&
            (temp->data.status == PENDING || temp->data.status == IN_PROGRESS)) {
            printf("[ERROR] 该患者已在 %s 预约了该医生，不能重复挂号\n", appointmentDate);
            return 0;
        }
        temp = temp->next;
    }

    // 4. 分配新节点
    Registration* newNode = (Registration*)malloc(sizeof(Registration));
    if (newNode == NULL) {
        printf("[ERROR] 内存分配失败\n");
        return 0;
    }
    newNode->next = newNode->pre = NULL;

    // 5. 生成挂号单号
    char id[20];
    generateUniqueId("REG", id);
    strcpy(newNode->data.regNo, id);

    // 6. 填充患者和医生信息
    strcpy(newNode->data.patientCardNo, patientCardNo);
    strcpy(newNode->data.patientName, patientName);
    strcpy(newNode->data.doctorEmpNo, doctorEmpNo);
    strcpy(newNode->data.doctorName, doctorName);
    strcpy(newNode->data.dept, dept);

    // 7. 设置挂号日期时间（系统当前时间）
    int hour, minute, second;
    time_t now = time(0);
    struct tm* timeinfo = localtime(&now);
    getCurrentTime(&year, &month, &day);
    hour = timeinfo->tm_hour;
    minute = timeinfo->tm_min;
    second = timeinfo->tm_sec;

    sprintf(newNode->data.date, "%04d-%02d-%02d", year, month, day);
    sprintf(newNode->data.time, "%02d:%02d:%02d", hour, minute, second);

    // 8. 设置预约日期时间（由调用方传入）
    strcpy(newNode->data.appointmentDate, appointmentDate);
    strcpy(newNode->data.appointmentTime, appointmentTime);

    // 9. 设置初始状态和挂号方式
    newNode->data.status = PENDING;
    newNode->data.createdBy = createdBy;
    newNode->data.consultationFee = 0.0f;
    strcpy(newNode->data.remarks, "");

    // 10. 尾插法插入链表
    if (*tail == NULL) {
        *head = newNode;
        *tail = newNode;
    } else {
        (*tail)->next = newNode;
        newNode->pre = *tail;
        *tail = newNode;
    }

    // 11. 当天挂号才增加医生接诊数
    if (strcmp(appointmentDate, today) == 0) {
        incrementPatientCount(d);
    }

    // 12. 保存到文件
    rebuildRegistrationFile(*head);

    // 13. 输出成功信息（根据挂号方式区分提示）
    if (createdBy == PATIENT) {
        printf("[OK] 预约挂号成功！\n");
        printf("  挂号编号：%s\n", newNode->data.regNo);
        printf("  患者：%s\n", newNode->data.patientName);
        printf("  医生：%s（%s）\n", newNode->data.doctorName, newNode->data.dept);
        printf("  预约日期：%s %s\n", newNode->data.appointmentDate, newNode->data.appointmentTime);
    } else {
        printf("[OK] 现场挂号成功！\n");
        printf("  挂号编号：%s\n", newNode->data.regNo);
        printf("  患者：%s\n", newNode->data.patientName);
        printf("  医生：%s（%s）\n", newNode->data.doctorName, newNode->data.dept);
        printf("  挂号日期：%s（今日）\n", newNode->data.date);
    }

    return 1;
}
```

### 3.2 实现 callNextPatient() — 医生叫号

**功能说明**：医生完成当前患者诊疗后，点击"叫号"按钮，系统自动从候诊队列中按**挂号时间先后顺序**找到该医生的第一个待就诊患者，将其状态改为"就诊中"，并显示叫号信息。

**实现思路**：
1. 遍历挂号链表，筛选出 `doctorEmpNo` 匹配且 `status == PENDING` 的记录
2. 按 `appointmentDate` + `appointmentTime` 排序（先挂号的先叫）
3. 取第一条（最早的），将其状态改为 `IN_PROGRESS`
4. 保存文件，输出叫号信息

**完整实现**：

```c
//-------------------------
// 医生叫号
// 功能：按挂号时间顺序叫下一位待就诊患者
// 参数：head/tail — 挂号链表，doctorEmpNo — 医生工号
// 返回值：1=叫号成功，0=无待就诊患者
//-------------------------
int callNextPatient(Registration** head, Registration** tail,
    char* doctorEmpNo)
{
    if (head == NULL || *head == NULL) {
        printf("[INFO] 暂无挂号记录\n");
        return 0;
    }

    // 1. 查找该医生的第一个 PENDING 状态挂号（按预约时间排序）
    Registration* current = *head;
    Registration* target = NULL;

    while (current != NULL) {
        if (strcmp(current->data.doctorEmpNo, doctorEmpNo) == 0 &&
            current->data.status == PENDING) {
            // 找到第一个匹配的后，与 target 比较预约时间，取更早的
            if (target == NULL) {
                target = current;
            } else {
                // 比较 appointmentDate，更早的优先
                int cmpDate = compareDateStr(current->data.appointmentDate,
                                              target->data.appointmentDate);
                if (cmpDate < 0) {
                    target = current;
                } else if (cmpDate == 0) {
                    // 日期相同则比较 appointmentTime
                    if (strcmp(current->data.appointmentTime,
                               target->data.appointmentTime) < 0) {
                        target = current;
                    }
                }
            }
        }
        current = current->next;
    }

    // 2. 检查是否找到待就诊患者
    if (target == NULL) {
        printf("[INFO] 该医生暂无待就诊患者\n");
        return 0;
    }

    // 3. 修改状态为"就诊中"
    target->data.status = IN_PROGRESS;

    // 4. 保存到文件
    rebuildRegistrationFile(*head);

    // 5. 输出叫号信息（模拟诊室广播）
    printf("\n╔═══════════════════════════════════════════╗\n");
    printf("║           叫 号 通 知                     ║\n");
    printf("╠═══════════════════════════════════════════╣\n");
    printf("║  请患者 %-20s 到 %-10s 诊室 ║\n",
           target->data.patientName, target->data.doctorName);
    printf("║  挂号编号：%-30s     ║\n", target->data.regNo);
    printf("╚═══════════════════════════════════════════╝\n");

    return 1;
}
```

> **辅助函数**：需要在 `utils.c` 中补充字符串日期比较函数，或在 `callNextPatient()` 上方添加：
> ```c

> int compareDateStr(char* date1, char* date2) {
>     int y1, m1, d1, y2, m2, d2;
>     sscanf(date1, "%d-%d-%d", &y1, &m1, &d1);

> }
> ```

### 3.3 新增 buildWaitingQueue() — 生成候诊队列

**功能说明**：为指定医生构建当天的候诊队列，按 `appointmentTime` 排序，仅包含 `PENDING` 状态的挂号。

```c
//-------------------------
// 生成指定医生的当天候诊队列
// 功能：筛选出 doctorEmpNo 匹配、当天预约、PENDING 状态的挂号，按时间排序
// 参数：head — 挂号链表头，doctorEmpNo — 医生工号，today — 当天日期（YYYY-MM-DD）
// 返回值：新的有序链表头指针（调用方负责释放）
//-------------------------
Registration* buildWaitingQueue(Registration* head, char* doctorEmpNo, char* today)
{
    Registration* resultHead = NULL;
    Registration* resultTail = NULL;
    Registration* cur = head;

    while (cur != NULL) {
        // 筛选条件：同医生、当天、待就诊
        if (strcmp(cur->data.doctorEmpNo, doctorEmpNo) == 0 &&
            strcmp(cur->data.appointmentDate, today) == 0 &&
            cur->data.status == PENDING) {

            // 创建新节点复制数据
            Registration* newNode = (Registration*)malloc(sizeof(Registration));
            if (newNode == NULL) continue;
            newNode->data = cur->data;
            newNode->next = newNode->pre = NULL;

            // 按 appointmentTime 插入有序链表（升序）
            if (resultHead == NULL) {
                resultHead = newNode;
                resultTail = newNode;
            } else {
                Registration* pos = resultHead;
                Registration* prev = NULL;
                while (pos != NULL &&
                       strcmp(pos->data.appointmentTime, newNode->data.appointmentTime) < 0) {
                    prev = pos;
                    pos = pos->next;
                }
                if (prev == NULL) {
                    // 插入头部
                    newNode->next = resultHead;
                    resultHead->pre = newNode;
                    resultHead = newNode;
                } else {
                    newNode->next = pos;
                    newNode->pre = prev;
                    prev->next = newNode;
                    if (pos != NULL) pos->pre = newNode;
                    else resultTail = newNode;
                }
            }
        }
        cur = cur->next;
    }

    return resultHead;
}
```

### 3.6 完善 cancelRegistration() — 区分当天与非当天

**现有问题**：当前 `cancelRegistration()` 只要 `currentPatients > 0` 就直接减，没有判断是否是当天挂号。

**修复后**：

```c
int cancelRegistration(Registration** head, Registration** tail, Registration* r)
{
    if (r == NULL) {
        printf("[ERROR] 未找到对应记录\n");
        return 0;
    }

    // 只有 PENDING 状态的才能取消
    if (r->data.status != PENDING) {
        printf("[ERROR] 只有待就诊状态的挂号才能取消（当前状态：%d）\n", r->data.status);
        return 0;
    }

    // 获取当天日期
    int year, month, day;
    getCurrentTime(&year, &month, &day);
    char today[20];
    sprintf(today, "%04d-%02d-%02d", year, month, day);

    // 只有当天挂号才减少医生接诊数（释放号源）
    if (strcmp(r->data.appointmentDate, today) == 0) {
        Doctor* d = findDoctorByEmpNo(g_doctorHead, r->data.doctorEmpNo);
        if (d != NULL && d->data.currentPatients > 0) {
            d->data.currentPatients--;
        }
    }

    // 修改状态为已取消
    r->data.status = CANCELLED;

    // 保存文件
    rebuildRegistrationFile(*head);
    printf("[OK] 挂号 %s 已取消，号源已释放\n", r->data.regNo);
    return 1;
}
```

### 3.7 完善 listAllRegistrations() — 显示完整信息

```c
void listAllRegistrations(Registration* head)
{
    if (head == NULL) {
        printf("暂无挂号信息\n");
        return;
    }

    printf("\n=== 挂号记录列表 ===\n");
    printf("%-14s %-10s %-10s %-10s %-12s %-10s %-10s %-8s\n",
           "挂号编号", "患者姓名", "医生姓名", "科室",
           "预约时间", "状态", "方式", "日期");
    printf("────────────────────────────────────────────────────────────────────\n");

    Registration* cur = head;
    int count = 0;
    while (cur != NULL) {
        // 状态转字符串
        char* statusStr;
        switch (cur->data.status) {
            case PENDING:     statusStr = "待就诊"; break;
            case IN_PROGRESS: statusStr = "就诊中"; break;
            case COMPLETED:   statusStr = "已完成"; break;
            case CANCELLED:   statusStr = "已取消"; break;
            default:          statusStr = "未知";
        }

        // 方式转字符串
```

```c
//-------------------------
// 患者取消自己的挂号（带权限校验：只能取消自己的、PENDING 状态的）
// 参数：regHead/regTail — 挂号链表，patientCardNo — 患者卡号，regNo — 挂号编号

int patientCancelRegistration(Registration** regHead, Registration** regTail,
    char* patientCardNo, char* regNo)
{

        printf("[ERROR] 未找到挂号编号 %s\n", regNo);

        printf("[ERROR] 无权取消他人的挂号记录\n");
        return 0;
    }

    // 3. 调用通用取消函数
    return cancelRegistration(regHead, regTail, r);
}
```

```c
    char today[20];

        Registration* tmp = cur;
        cur = cur->next;
        free(tmp);
    }
}
```

```c
void showRegistrationManagement(void)
{
    int choice;
    char patientCardNo[20], patientName[50];
    char doctorEmpNo[20], doctorName[50], dept[50];
    char regNo[20], appointmentDate[20], appointmentTime[20];

                addRegistration(&g_regHead, &g_regTail,
                                patientCardNo, patientName,
                                doctorEmpNo, doctorName, dept,
                                appointmentDate, appointmentTime, PATIENT);
                break;
            }

            // ──────────── 患者：取消挂号 ────────────
            case 2: {
                printf("请输入您的卡号: ");      scanf("%19s", patientCardNo);
                printf("请输入要取消的挂号编号: "); scanf("%19s", regNo);
                patientCancelRegistration(&g_regHead, &g_regTail,

            // ──────────── 护士：现场挂号 ────────────
            case 3: {

                Patient* p = findPatientByCardNo(g_patientHead, patientCardNo);

                                d->data.empNo, today);

                            while (cur != NULL) {
                                Registration* tmp = cur;
                                cur = cur->next;

                    }
                } else {
                    doctorViewWaitingList(g_regHead, doctorEmpNo);
                }
                break;

                Registration* r = findRegistrationByNo(g_regHead, regNo);
                if (r) {
                    completeRegistration(r);

                listAllRegistrations(g_regHead);
                break;
            }

            case 0:
                return;

            default:
                printf("[ERROR] 无效选择\n");
        }
    }
}
```

```
2026-05-07                           ← 预约日期
09:30                                ← 预约时间
```

## 11. 测试建议

按以下顺序逐步验证：

1. **现场挂号**：以护士身份为张三挂内科刘医生的号 → 确认 `currentPatients+1`
2. **再次现场挂号**：同一医生挂满到 `maxPatients` → 确认提示"号源已满"
3. **重复挂号检查**：同一患者同一天同一医生 → 确认提示"不能重复挂号"
4. **预约挂号**：以患者身份预约明天同一医生 → 确认成功（不占今天号源）
5. **查看候诊队列**：选项 7 → 确认显示有序队列
6. **医生叫号**：选项 6 → 确认最早挂号的变成"就诊中"
7. **再次叫号**：确认按时间顺序依次叫号
8. **完成就诊**：选项 8 → 确认状态变为"已完成"
9. **患者取消**：选项 2 → 确认 PENDING 的能取消，IN_PROGRESS 的不能取消
10. **查看个人记录**：选项 4 → 确认只显示当前患者的记录
