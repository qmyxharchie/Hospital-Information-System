# 挂号模块 - 教程文档

> 本文档详细介绍挂号记录管理模块

---

## 1. 模块概述

### 1.1 功能描述

挂号模块负责管理病人的挂号记录：
- 病人挂号（自动检查医生名额）
- 取消挂号
- 完成就诊
- 时间范围查询

### 1.2 业务规则

1. 病人必须存在
2. 医生必须有剩余名额
3. 同一医生同时只能有一个待就诊挂号

---

## 2. 数据结构

```c
// registration.h
typedef struct Registration {
    char regNo[20];               // 挂号单号（如REG001）
    char patientCardNo[20];       // 病人卡号
    char patientName[50];        // 病人姓名
    char doctorEmpNo[20];        // 医生工号
    char doctorName[50];         // 医生姓名
    char dept[50];               // 科室
    char date[20];               // 挂号日期
    char status[20];             // 状态（待就诊/已完成/已取消）
    
    struct Registration* next;
    struct Registration* pre;
} Registration;
```

## 3. 核心函数

### 3.1 挂号

```c
int addRegistration(Registration** head, Registration** tail,
                    char* patientCardNo, char* patientName,
                    char* doctorEmpNo, char* doctorName, char* dept) {
    
    // 检查医生是否有剩余名额
    Doctor* d = findDoctorByEmpNo(g_doctorHead, doctorEmpNo);
    if (d == NULL) {
        printf("[ERROR] 医生不存在！\n");
        return 0;
    }
    
    if (d->currentPatients >= d->maxPatients) {
        printf("[ERROR] 医生今日已满号！\n");
        return 0;
    }
    
    // 创建挂号记录
    Registration* now = (Registration*)malloc(sizeof(Registration));
    now->next = now->pre = NULL;
    
    sprintf(now->regNo, "REG%s", generateUniqueId());
    safeStringCopy(now->patientCardNo, patientCardNo, 20);
    safeStringCopy(now->patientName, patientName, 50);
    safeStringCopy(now->doctorEmpNo, doctorEmpNo, 20);
    safeStringCopy(now->doctorName, doctorName, 50);
    safeStringCopy(now->dept, dept, 50);
    getCurrentTime(now->date, 20);
    strcpy(now->status, "待就诊");
    
    // 插入链表
    if (*head == NULL) {
        *head = *tail = now;
    } else {
        (*tail)->next = now;
        now->pre = *tail;
        *tail = now;
    }
    
    // 更新医生接诊数
    d->currentPatients++;
    
    printf("[INFO] 挂号成功！单号：%s\n", now->regNo);
    return 1;
}
```

### 3.2 取消挂号

```c
int cancelRegistration(Registration** head, Registration** tail, Registration* r) {
    if (r == NULL) return 0;
    
    if (strcmp(r->status, "已完成") == 0) {
        printf("[ERROR] 已完成的挂号不能取消！\n");
        return 0;
    }
    
    // 更新医生接诊数
    Doctor* d = findDoctorByEmpNo(g_doctorHead, r->doctorEmpNo);
    if (d != NULL && d->currentPatients > 0) {
        d->currentPatients--;
    }
    
    strcpy(r->status, "已取消");
    printf("[INFO] 取消挂号成功！\n");
    return 1;
}
```

### 3.3 完成就诊

```c
int completeRegistration(Registration* r) {
    if (r == NULL) return 0;
    
    if (strcmp(r->status, "待就诊") != 0) {
        printf("[ERROR] 只有待就诊的挂号可以完成！\n");
        return 0;
    }
    
    strcpy(r->status, "已完成");
    printf("[INFO] 就诊完成！\n");
    return 1;
}
```
