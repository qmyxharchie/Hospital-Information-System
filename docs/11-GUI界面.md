## 1. StellarX框架介绍

### 1.1 什么是StellarX？

StellarX 是一个基于 EasyX 的现代化 C++ GUI 框架，轻量级、组件化设计，支持多种控件。

- GitHub: https://github.com/Ysm-04/StellarX
- 官网: https://stellarx-gui.top

### 1.2 项目引用方式

**提示**：在 main_gui.cpp 中需要包含：
- `#include "StellarX/StellarX.h"` 或具体组件头文件
- 所有组件在 `StellarX` 命名空间下

## 2. 核心组件

### 2.1 Window（窗口）

**组件作用**：GUI 的主容器，所有其他组件都放在窗口里。

**提示**：创建窗口时指定：宽、高、父窗口（填 nullptr）、背景色、标题文字。然后调用 draw() 绘制窗口，再用 runEventLoop() 启动事件循环。

### 2.2 Button（按钮）

**组件作用**：用户点击触发操作，对应命令行中的"请选择："交互。

**提示**：创建时指定：x坐标、y坐标、宽度、高度、按钮文字。
- 使用 `setOnClickListener()` 绑定点击事件（传入一个 lambda 或函数）
- 最后用 `addControl()` 添加到窗口中

### 2.3 TextBox（文本框）

**组件作用**：用户输入文字，对应命令行中的 scanf。

**提示**：
- 创建时指定位置和大小
- 用 `getText()` 获取用户输入内容（返回 string）
- 用 `setText()` 设置默认/预填充文字
- 用 `clear()` 清空内容

### 2.4 Label（标签）

**组件作用**：显示文字，对应 printf 的输出。

**提示**：
- 创建时指定：x坐标、y坐标、显示文字
- 用 `textStyle` 设置字体大小和字体名称（提示：nHeight 控制字号，lpszFace 控制字体）
- 可通过 `setText()` 动态更新显示内容

### 2.5 Table（表格）

**组件作用**：以表格形式显示数据列表，对应 listAllXxx() 遍历打印。

**提示**：
- 创建时指定位置和大小
- 用 `setHeaderText(列序号, "列名")` 设置表头
- 用 `setCellText(行号, 列号, "内容")` 填充单元格
- 用 `clear()` 清空表格重新加载数据
- 用 `setRowCount()` 设置行数

### 2.6 TabControl（选项卡）

**组件作用**：左侧导航栏，点击不同标签切换不同模块页面，对应命令行中的多级菜单。

**提示**：
- 创建时指定位置和大小
- 用 `setTabPlacement(Left)` 设置标签在左侧
- 用 `add()` 添加页面，每个页面是一个 pair（左侧标签按钮，内容画布）
- 用 Canvas 作为每个页面的容器，在上面放表格、按钮等

## 3. 主程序结构

**提示**：GUI 程序入口不是 `main()`，而是 `WinMain()`。

整体结构分为 6 步：
1. **创建主窗口**：设置大小和标题
2. **创建登录页面组件**：TextBox（用户名/密码）、Button（登录按钮）、Label（提示文字）
3. **创建主页面 TabControl**：添加各模块标签（病人/医生/挂号/药品/住院/统计等）
4. **为每个 Button 绑定事件处理函数**：登录按钮 → 调用登录逻辑；各模块的增删改查按钮 → 调用对应的 .c 模块函数
5. **将所有组件添加到窗口**
6. **绘制并启动事件循环**：先 draw() 背景图，再 runEventLoop()

## 4. 布局示例

```
┌────┬──────────────────────────────────────┐
│ 病人 │                                      │
├────┤  内容区域（Canvas）                    │
│ 医生 │  ┌────────────────────────────────┐ │
├────┤  │  Table（表格显示数据）           │ │
│ 挂号 │  └────────────────────────────────┘ │
├────┤  ┌────────────────────────────────┐ │
│ 药品 │  │  TextBox + Button（操作区）    │ │
├────┤  └────────────────────────────────┘ │
│ 住院 │  [添加] [删除] [刷新] [搜索]        │
└────┴──────────────────────────────────────┘
```

**提示**：左侧 TabControl 提供导航，右侧 Canvas 放置 Table 展示数据和 TextBox/Button 进行操作。
