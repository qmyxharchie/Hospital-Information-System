## 1. 文件存储概述

### 1.1 为什么用文本文件？

- 简单易用，无需数据库
- 便于调试和查看数据
- 适合小型项目
- 无需额外安装软件

## 2. 文件格式设计

### 2.1 通用格式

```
1            ← 1=有效记录
数据1
数据2
数据3
...

1            ← 下一条记录
数据1
...

-1           ← 文件结束标记
```

### 2.2 格式说明

| 标记 | 含义 |
|------|------|
| `1` | 记录有效 |
| `-1` | 文件结束 |

## 3. 读取文件

### 3.1 基本流程

```c
void buildPatientChain(Patient** head, Patient** tail) {
    FILE* fp = fopen(PATIENT_FILE, "r");
    *head = *tail = NULL;
    
    if (fp == NULL) {
        // 文件不存在则创建
        fp = fopen(PATIENT_FILE, "w");
        fprintf(fp, "-1");
        fclose(fp);
        return;
    }
    
    Patient* pre = NULL;
    
    while (1) {
        int opt;
        fscanf(fp, "%d", &opt);
        
        if (opt == -1) break;
        
        if (opt == 1) {
            Patient* now = (Patient*)malloc(sizeof(Patient));
            now->next = now->pre = NULL;
            
            fscanf(fp, "%s", now->cardNo);
            fscanf(fp, "%s", now->name);
            // ... 读取其他字段
            
            if (*head == NULL) {
                *head = now;
            } else {
                pre->next = now;
                now->pre = pre;
            }
            pre = now;
        }
    }
    
    *tail = pre;
    fclose(fp);
}
```

## 4. 写入文件

### 4.1 基本流程

```c
void rebuildPatientFile(Patient* head) {
    FILE* fp = fopen(PATIENT_FILE, "w");
    
    if (fp == NULL) return;
    
    Patient* p = head;
    while (p != NULL) {
        fprintf(fp, "1\n");
        fprintf(fp, "%s\n", p->cardNo);
        fprintf(fp, "%s\n", p->name);
        fprintf(fp, "%s\n", p->gender);
        fprintf(fp, "%s\n", p->idCard);
        fprintf(fp, "%s\n", p->phone);
        fprintf(fp, "%d\n", p->isActive);
        fprintf(fp, "\n");
        p = p->next;
    }
    
    fprintf(fp, "-1\n");
    fclose(fp);
}
```
