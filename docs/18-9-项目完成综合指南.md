## 4. 项目编译和运行

### 4.1 控制台版本编译

```bash
# 编译控制台版本
gcc -o hospital_console.exe src/main.c src/login.c src/patient.c src/doctor.c src/registration.c src/file_io.c src/utils.c -I./include

# 运行控制台版本
./hospital_console.exe
```

### 4.2 GUI版本编译

```bash
# 编译GUI版本（需要StellarX框架）
g++ -o hospital_gui.exe src/main_gui.cpp src/login.c src/patient.c src/doctor.c src/registration.c src/file_io.c src/utils.c src/ui.c -I./include -lwinmm -lgdi32 -lcomdlg32 -lole32 -loleaut32 -luuid -static-libgcc -static-libstdc++

# 运行GUI版本
./hospital_gui.exe
```

### 4.3 编译注意事项

- 确保所有依赖库已安装
- 检查头文件路径是否正确
- 注意C和C++混编的编译选项
- 确保数据目录存在
