# 医院综合信息管理系统 - 开发计划

## 项目概述

本项目是为吉林大学软件工程专业《程序设计基础课程设计》开发的小型医院角色综合信息管理系统。

## 功能需求

### 1. 病人信息管理
- 添加病人信息（卡号、姓名、性别、身份证、联系电话）
- 删除、修改、查询病人信息
- 住院状态跟踪

### 2. 医生信息管理
- 添加医生（工号、姓名、科室、出诊时间）
- 每日接诊数量限制
- 医生增删改查

### 3. 挂号记录管理
- 病人挂号（自动检查医生名额）
- 取消挂号、完成就诊
- 时间范围查询

### 4. 药品信息管理
- 药品增删改查
- 库存管理
- **库存预警**：库存低于最低值时提示
- **购药记录**：扣减库存

### 5. 住院记录管理
- 入院登记（自动分配床位）
- 出院结算（计算费用、释放床位）
- 住院状态跟踪

### 6. 床位信息管理
- 床位增删改查
- 病区管理
- 床位状态跟踪（空闲/占用/维修）

### 7. 统计报表
- 医生业务量统计
- 科室统计
- 收入汇总

### 8. 查询功能
- 按病人卡号/姓名查询
- 按时间范围查询
- 综合查询

## 技术架构

### 数据结构
- **双向链表**：所有数据使用双向链表存储
- **文件存储**：启动加载、退出保存
- **数据备份**：每次启动自动备份

## 编译运行

### Windows (Visual Studio / VS Code)
```bash
# 使用CMake构建
mkdir build
cd build
cmake ..
cmake --build . --config Release
.\bin\hospital_management.exe
```

### 依赖
- C11标准
- Windows API（用于文件操作）
- EasyX图形库（可选，用于GUI）

## 数据格式

### 病人信息 (patient.txt)
```
1
PT20260407142530
张三
男
220102199001011234
13800138000
0
```
- 格式：1(有效) + 卡号 + 姓名 + 性别 + 身份证 + 电话 + 住院状态
- 结束标记：-1

### 医生信息 (doctor.txt)
```
1
DOC001
李医生
内科
周一、周三、周五
30
0
```

## 开发注意事项

1. **数据一致性**：修改数据后要及时保存到文件
2. **内存管理**：使用malloc后要在适当时机free
3. **输入验证**：检查手机号、身份证号格式
4. **容错处理**：文件不存在时自动创建
5. **备份机制**：每次启动自动备份，防止数据丢失
