## 1. 模块概述

### 1.1 功能描述

挂号模块负责管理病人的挂号记录：
- 病人挂号（自动检查医生名额）
- 取消挂号
- 完成就诊
- 时间范围查询

### 1.2 业务规则

1. 病人必须存在（应先添加病人）
2. 医生必须有剩余名额（currentPatients < maxPatients）
3. 同一医生同时只能有一个"待就诊"状态的挂号

## 2. 数据结构

在 `registration.h` 中定义 Registration 结构体：

```c
// registration.h
typedef struct RegistrationData {
    char regNo[20];       // 挂号单号（如"REG001"）
    char patientCardNo[20];  // 病人卡号
    char patientName[50];  // 病人姓名（冗余存储，便于显示）
    char doctorEmpNo[20];  // 医生工号
    char doctorName[50];   // 医生姓名（冗余存储）
    char dept[50];         // 科室
    char date[20];         // 挂号日期
    char status[20];       // 状态（待就诊/已完成/已取消）
} RegistrationData;
```

```c
// registration.h
typedef struct Registration {
    RegistrationData data;
    struct Registration* next;
    struct Registration* pre;
} Registration;
```

### 3.1 挂号（最核心的函数）

```c
// registration.h
int addRegistration(Registration** head, Registration** tail,
    char* patientCardNo, char* patientName,
    char* doctorEmpNo, char* doctorName, char* dept);
```

**实现思路（关键！涉及跨模块调用）**：
1. **第1步**：调用 `findDoctorByEmpNo(g_doctorHead, doctorEmpNo)` 验证医生是否存在，找不到则打印错误，返回 0
2. **第2步**：检查医生是否还有名额：`canAcceptPatient(*foundDoctor)`，如果返回 0（已满），打印"医生今日号已满"，返回 0
3. **第3步**：`malloc(sizeof(Registration))` 分配节点
4. **第4步**：调用 `generateUniqueId("REG", id)` 生成挂号单号，加"REG"前缀
5. **第5步**：填充所有字段（regNo、patientCardNo、patientName、doctorEmpNo、doctorName、dept）
6. **第6步**：调用 `getCurrentTime` 获取当前日期，填充 date，`strcpy(status, "待就诊")`
7. **第7步**：尾插法插入链表
8. **第8步（重要）**：调用 `incrementPatientCount(*foundDoctor)`，将医生的 `currentPatients++`，因为挂了一个号占了一个名额
9. **第9步**：调用 `rebuildRegistrationFile(*head)` 保存
10. **第10步**：打印挂号成功信息，返回 1

**⚠️ 注意**：此函数内部需要能访问 `g_doctorHead`（医生链表头指针），这是跨模块数据共享的例子。

### 3.2 取消挂号

```c
// registration.h
int cancelRegistration(Registration** head, Registration** tail, Registration* r);
```

**实现思路**：
1. **第1步**：边界检查（r==NULL 返回 0）
2. **第2步**：如果 `strcmp(r->data.status, "已完成") == 0`，打印"已完成的就诊无法取消"，返回 0
3. **第3步**：找到对应的医生：`findDoctorByEmpNo(g_doctorHead, r->data.doctorEmpNo)`
4. **第4步**：调用 `incrementPatientCount` 恢复医生名额（或手动 `doctor->data.currentPatients--`）
5. **第5步**：`strcpy(r->data.status, "已取消")`
6. **第6步**：调用 `rebuildRegistrationFile(*head)` 保存
7. **第7步**：打印取消成功信息，返回 1

---

### 3.3 完成就诊

```c
// registration.h
int completeRegistration(Registration* r);
```

**实现思路**：
1. **第1步**：边界检查（r==NULL 返回 0）
2. **第2步**：如果 `strcmp(r->data.status, "待就诊") != 0`，打印错误，返回 0
3. **第3步**：`strcpy(r->data.status, "已完成")`
4. **第4步**：打印完成就诊信息，返回 1
5. **注意**：完成就诊**不需要**减医生接诊数，因为名额是在挂号时占用的，就诊只是标记为完成

### 3.4 查询函数

```c
// registration.h
Registration* findRegistrationByNo(Registration* head, char* regNo);              // 按挂号单号查
Registration* findRegistrationsByPatient(Registration* head, char* patientCardNo);  // 按病人卡号查
// [修正备注-20260412] 原函数名 findRegistrationsByDoctor 暗示返回多个结果（复数），但实际返回单指针。
// 为避免误解改为单数形式，若确实需要多结果应改为返回链表或数组。
Registration* findRegistrationByDoctor(Registration* head, char* doctorEmpNo);       // 按医生查
Registration* findRegistrationsByDateRange(Registration* head, int y1, int m1, int d1, int y2, int m2, int d2);  // 时间范围查
```

**实现思路**：
1. **第1步**：`Registration* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历链表
3. **第3步**：按条件比对各字段
4. **第4步**：找到则返回 `cur`，遍历完返回 `NULL`
