# 病人模块 - 教程文档

> 本文档详细介绍病人信息管理模块的实现

---

## 1. 模块概述

### 1.1 功能描述

病人模块负责管理病人的基本信息，包括：
- 添加新病人（自动生成门诊卡号）
- 删除病人
- 修改病人信息
- 查询病人
- 列表显示所有病人

### 1.2 数据存储

- **数据文件**：`data/patient.txt`
- **唯一标识**：门诊卡号（格式：PT + 时间戳）

---

## 2. 数据结构

```c
// patient.h
typedef struct Patient {
    char cardNo[20];          // 门诊卡号（唯一标识）
    char name[50];            // 姓名
    char gender[10];          // 性别
    char idCard[20];          // 身份证号
    char phone[15];           // 联系电话
    int isActive;             // 是否住院（0=否，1=是）
    
    struct Patient* next;     // 下一个节点
    struct Patient* pre;     // 上一个节点
} Patient;
```

## 3. 函数详解

### 3.1 从文件加载数据

```c
void buildPatientChain(Patient** head, Patient** tail) {
    FILE* fp = fopen(PATIENT_FILE, "r");
    *head = *tail = NULL;
    
    if (fp == NULL) {
        // 文件不存在则创建空文件
        fp = fopen(PATIENT_FILE, "w");
        if (fp) {
            fprintf(fp, "-1");
            fclose(fp);
        }
        return;
    }
    
    Patient* pre = NULL;
    
    while (1) {
        int opt;
        fscanf(fp, "%d", &opt);
        
        if (opt == -1) break;  // 文件结束
        
        if (opt == 1) {
            // 读取一条病人记录
            Patient* now = (Patient*)malloc(sizeof(Patient));
            now->next = now->pre = NULL;
            
            fscanf(fp, "%s", now->cardNo);
            fscanf(fp, "%s", now->name);
            fscanf(fp, "%s", now->gender);
            fscanf(fp, "%s", now->idCard);
            fscanf(fp, "%s", now->phone);
            fscanf(fp, "%d", &now->isActive);
            
            // 插入链表
            if (*head == NULL) {
                *head = now;
            } else {
                pre->next = now;
                now->pre = pre;
            }
            pre = now;
        }
    }
    
    *tail = pre;
    fclose(fp);
}
```

**文件格式**：
```
1                           ← 有效记录
PT20260407142530           ← 卡号
张三                        ← 姓名
男                          ← 性别
220102199001011234          ← 身份证
13800138000                 ← 电话
0                           ← 住院状态

-1                          ← 结束
```

### 3.2 添加病人

```c
void addPatient(Patient** head, Patient** tail, 
                char name[], char gender[], char idCard[], char phone[]) {
    
    // 1. 分配内存
    Patient* now = (Patient*)malloc(sizeof(Patient));
    now->next = now->pre = NULL;
    
    // 2. 填充数据
    safeStringCopy(now->name, name, 50);
    safeStringCopy(now->gender, gender, 10);
    safeStringCopy(now->idCard, idCard, 20);
    safeStringCopy(now->phone, phone, 15);
    now->isActive = 0;
    
    // 3. 生成唯一卡号
    sprintf(now->cardNo, "PT%s", generateUniqueId());
    
    // 4. 插入链表尾部
    if (*head == NULL) {
        *head = *tail = now;
    } else {
        (*tail)->next = now;
        now->pre = *tail;
        *tail = now;
    }
    
    printf("[INFO] 添加病人成功！卡号：%s\n", now->cardNo);
}
```

**卡号生成规则**：`PT` + 时间戳字符串

```
PT + 20260407142530 = PT20260407142530
```
