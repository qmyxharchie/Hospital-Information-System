# 床位模块 - 学习版

> 本文档为学习版，代码部分已替换为函数名和实现思路提示。
> 结构体采用 Data + Node 分离模式，每个函数标注返回类型和头文件来源。

---

## 1. 模块概述

### 1.1 功能描述

**床位管理**：床位增删改查、病区管理、床位状态跟踪（空闲/占用/维修）。

### 1.2 核心亮点

**按病区管理**：支持按病区查看床位使用情况，方便护士站统筹调度。

## 2. 数据结构

在 `bed.h` 中定义：

### 2.1 床位结构体

```c
// bed.h
// [修正备注-20260412] 原 typedef struct BedData { ... } Bed;
// 类型别名与 Data 命名风格不一致，已统一为纯 BedData 命名。
typedef struct BedData {
    char ward[30];             // 病区（如"内科一病区"）
    char bedNo[20];            // 床位号（唯一ID，如"BED001"）
    char patientCardNo[20];   // 占用病人卡号（空床为"空"）
    char patientName[50];      // 占用病人姓名
    char status[20];           // 状态：空闲、占用、维修
} BedData;
```

```c
// bed.h
typedef struct BedNode {
    BedData data;
    struct BedNode* next;
    struct BedNode* pre;
} BedNode;
```

## 3. 核心函数

> **统一格式**：`[返回类型] 函数名(...)` — 所属头文件

---

### 3.1 自动分配床位

```c
// bed.h
char* allocateBed(BedNode* head, char* patientCardNo, char* patientName);
```

**实现思路**：
1. **第1步**：`BedNode* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历整个床位链表
3. **第3步**：找到第一个 `strcmp(cur->data.status, "空闲") == 0` 的床位
4. **第4步**：找到后：
   - `strcpy(cur->data.patientCardNo, patientCardNo)` 记录病人卡号
   - `strcpy(cur->data.patientName, patientName)` 记录病人姓名
   - `strcpy(cur->data.status, "占用")` 改为占用状态
5. **第5步**：打印分配成功信息，返回床位号
6. **第6步**：遍历完没有空闲床位，打印"暂无空闲床位"，返回 NULL

---

### 3.2 释放床位

```c
// bed.h
void freeBed(BedNode* b);
```

**实现思路**：
1. **第1步**：边界检查（b==NULL 直接返回）
2. **第2步**：`strcpy(b->data.patientCardNo, "空")` 清空病人卡号
3. **第3步**：`strcpy(b->data.patientName, "空")` 清空病人姓名
4. **第4步**：`strcpy(b->data.status, "空闲")` 改为空闲
5. **第5步**：打印释放成功信息

---

### 3.3 添加 / 删除床位

```c
// bed.h
void addBed(BedNode** head, BedNode** tail, char* ward, char* bedNo);    // 添加床位
void delBed(BedNode** head, BedNode** tail, BedNode* b);                 // 删除床位
```

**实现思路**：
- `addBed`：尾插法插入新节点，初始 `patientCardNo="空"`，`status="空闲"`
- `delBed`：先检查 `strcmp(b->data.status, "占用") == 0`，占用中不允许删除

---

### 3.4 查询函数

```c
// bed.h
BedNode* findBedByNo(BedNode* head, char* bedNo);              // 按床位号精确查找
BedNode* findBedsByWard(BedNode* head, char* ward);            // 按病区查找（返回第一个匹配）
BedNode* findAvailableBeds(BedNode* head);                      // 查找第一个空闲床位
```

**实现思路**：遍历链表，用 `strcmp` 匹配对应字段，找到返回节点指针，未找到返回 NULL。

---

### 3.5 病区统计

```c
// bed.h
void getWardStats(BedNode* head, char* ward, int* total, int* occupied);
```

**实现思路**：
1. **第1步**：初始化 `*total = 0, *occupied = 0`
2. **第2步**：遍历链表，统计指定病区床位总数
3. **第3步**：统计 `status == "占用"` 的数量填入 `*occupied`

---

### 3.6 列表显示

```c
// bed.h
void listAllBeds(BedNode* head);              // 所有床位列表
void listBedsByWard(BedNode* head, char* ward);  // 指定病区床位列表
```

**实现思路**：从头遍历链表，逐个 `printf` 打印各字段。

### 3.7 文件读写

void buildBedChain(BedNode** head, BedNode** tail);  // 从文件加载床位列表
