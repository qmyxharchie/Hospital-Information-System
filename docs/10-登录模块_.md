## 1. 模块概述

### 1.1 功能描述

登录模块负责用户身份验证：
- 用户登录
- 管理员登录
- 用户注册
- 密码加密存储

### 1.2 安全特性

**MD5密码加密**：密码不以明文存储，相同密码产生相同哈希值，不可逆向解密。

## 3. MD5加密

### 3.1 基本原理

**提示**：MD5 把任意长度的字符串转换为一个 128 位的哈希值（32位十六进制字符串）。相同输入一定产生相同输出，无法反推原始密码。

**本项目的使用方式**：只需要会**调用**，不需要手写算法。项目中已提供调用接口如下：

```c
// login.h
void md5Hash(const char* input, char* output);  // MD5加密函数
```

调用示例：
```c
char hashed[100];
md5Hash(password, hashed);  // 输入密码，输出哈希值存到 hashed 里
```

|--------|-----------|
| admin | 21232f297a57a5a743894a0e4a801fc3 |
| 123456 | e10adc3949ba59abbe56e057f20f883e |

### 4.1 用户登录

```c
// login.h
LoginStatus login(char username[], char password[]);
```

**实现思路**：
1. **第1步**：调用 `buildUserChain(&g_userHead, &g_userTail)` 加载所有用户
2. **第2步**：调用 `md5Hash(password, pwdHash)` 生成密码哈希
3. **第3步**：`User* cur = g_userHead`，`while(cur != NULL)` 遍历用户链表
4. **第4步**：`strcmp(cur->data.username, username) == 0 && strcmp(cur->data.password, pwdHash) == 0`
5. **第5步**：匹配成功 → 记录当前登录用户 `g_currentUsername`，角色 `g_currentUserRole`，`g_isLoggedIn = true`
6. **第6步**：调用 `getCurrentTime` 更新 `lastLogin`，调用 `rebuildUserFile(g_userHead)` 保存
7. **第7步**：返回对应状态（`LOGIN_SUCCESS_USER` / `LOGIN_SUCCESS_ADMIN`）
8. **第8步**：遍历完没找到，返回 `LOGIN_FAILED`

---

### 4.2 用户注册

```c
// login.h
int registerUser(char username[], char password[], int role);
```

**实现思路**：
1. **第1步**：调用 `buildUserChain(&g_userHead, &g_userTail)` 加载现有用户
2. **第2步**：遍历链表，检查用户名是否已存在：`strcmp(cur->data.username, username) == 0`
3. **第3步**：如果已存在，打印错误，返回 0
4. **第4步**：如果不存在：`malloc(sizeof(User))` 分配新节点
5. **第5步**：填充各字段，调用 `md5Hash(password, hashed)` 加密密码
6. **第6步**：尾插法插入链表
7. **第7步**：调用 `rebuildUserFile(g_userHead)` 保存到文件
8. **第8步**：打印注册成功，返回 1

---

### 4.3 文件读写

```c
// login.h
void buildUserChain(User** head, User** tail);   // 从文件加载用户列表
void rebuildUserFile(User* head);                 // 保存用户列表到文件（团队头文件中参数为 User 而非 User*）
void freeUserChain(User* head);                 // 释放用户链表内存
```

---

### 4.4 用户查询

```c
// login.h
User* findUserByName(User* head, char* username);
```

**实现思路**：
1. **第1步**：`User* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历链表
3. **第3步**：`strcmp(cur->data.username, username) == 0`
4. **第4步**：找到返回 `cur`，否则返回 `NULL`
