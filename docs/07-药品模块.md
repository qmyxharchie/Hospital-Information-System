# 药品模块 - 学习版

## 1. 模块概述

### 1.1 功能描述

药品模块负责管理药品的库存信息：
- 添加新药品
- 删除药品
- 修改药品信息
- 补充库存
- 库存预警检查
- 购药（扣减库存）

### 1.2 核心亮点

**库存预警机制**：每个药品设置最低库存值，当库存低于最低值时自动提示，方便药房管理。

## 3. 核心函数

### 3.1 库存预警检查

**函数名**：`checkLowStock(Medicine* head)`

**实现思路**：
1. 从 head 遍历整个链表
2. 检查 stock <= minStock
3. 如果低于阈值，打印预警信息
4. 统计并显示预警药品数量

### 3.2 购药（扣减库存）

**函数名**：`purchaseMedicine(Medicine* head, char* medNo, int quantity)`

**实现思路**：
1. 调用 `findMedicineByNo` 查找药品
2. 如果药品不存在，打印错误信息，返回0
3. 如果 stock < quantity，打印"库存不足"，返回0
4. 扣减库存：stock -= quantity
5. 打印购药成功和当前库存
6. **额外**：如果扣减后 stock <= minStock，再次调用预警提示
7. 返回1表示成功

### 3.3 补充库存

**函数名**：`replenishStock(Medicine* head, char* medNo, int quantity)`

**实现思路**：找到药品后，stock += quantity，打印补货成功信息。

### 3.4 购药记录

**函数名**：`addPurchaseRecord(Purchase** head, Purchase** tail, ...)`

**实现思路**：
1. malloc 分配 Purchase 节点
2. 填充所有字段（purNo用生成函数，date用时间函数）
3. 尾插法插入链表
4. 同时调用 `purchaseMedicine` 扣减对应药品库存

### 3.5 文件读写

**函数名**：`buildMedicineChain`、`rebuildMedicineFile`、`buildPurchaseChain`、`rebuildPurchaseFile`
