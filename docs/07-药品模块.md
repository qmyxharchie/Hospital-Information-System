# 药品模块 - 教程文档

> 本文档详细介绍药品信息管理模块的实现

---

## 1. 模块概述

### 1.1 功能描述

药品模块负责管理药品的库存信息，包括：
- 添加新药品
- 删除药品
- 修改药品信息
- 补充库存
- 库存预警检查
- 购药（扣减库存）

### 1.2 核心亮点

**库存预警机制**：
- 每个药品设置最低库存值
- 当库存低于最低值时自动提示
- 方便药房管理

## 2. 数据结构

// medicine.h
typedef struct Medicine {
    char medNo[20];              // 药品编号（如MED001）
    char genericName[50];        // 通用名

    char spec[50];              // 规格

## 3. 核心函数

### 3.1 库存预警

```c
void checkLowStock(Medicine* head) {
    Medicine* p = head;
    int count = 0;
    
    printf("\n========== 库存预警 ==========\n");
    while (p != NULL) {
        if (p->stock <= p->minStock) {
            printf("[预警] %s: 库存%d / 最低%d\n", 
                   p->genericName, p->stock, p->minStock);
            count++;
        }
        p = p->next;
    }
    
    if (count == 0) {
        printf("[INFO] 所有药品库存充足\n");
    }
    printf("==============================\n");
}
```

### 3.2 购药（扣减库存）

```c
int purchaseMedicine(Medicine* head, char* medNo, int quantity) {
    Medicine* m = findMedicineByNo(head, medNo);
    
    if (m == NULL) {
        printf("[ERROR] 药品不存在！\n");
        return 0;
    }
    
    if (m->stock < quantity) {
        printf("[ERROR] 库存不足！当前库存：%d\n", m->stock);
        return 0;
    }
    
    // 扣减库存
    m->stock -= quantity;
    printf("[INFO] 购药成功！扣减库存%d，当前库存：%d\n", 
           quantity, m->stock);
    
    // 检查是否需要预警
    if (m->stock <= m->minStock) {
        printf("[预警] %s 库存不足！\n", m->genericName);
    }
    
    return 1;
}
```
