# 医院综合信息管理系统

## 项目说明

本项目是吉林大学软件工程专业《程序设计基础课程设计》的医院信息管理系统。

## 功能模块

| 模块 | 功能 |
|------|------|
| 病人管理 | 门诊卡号、姓名、性别、身份证、电话、住院状态 |
| 医生管理 | 工号、姓名、科室、出诊时间、每日接诊上限 |
| 挂号管理 | 挂号单号、病人、医生、科室、日期、状态 |
| 药品管理 | 编号、通用名、商品名、规格、单价、库存预警 |
| 住院管理 | 住院单号、床位、预交金额、出院结算 |
| 床位管理 | 病区、床位号、状态、占用病人 |
| 登录系统 | 用户/管理员登录、注册、密码加密 |
| 统计报表 | 业务量、收入汇总等 |

## 编译

```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

## 运行

```bash
./bin/hospital_management.exe
```
