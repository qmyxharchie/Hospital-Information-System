## 1. 前置知识：指针基础回顾

### 1.1 什么是指针？

指针是存放**内存地址**的变量。

```c
int a = 10;
int* p = &a;   // p 保存了变量 a 的地址，& 是"取地址"运算符
printf("%d", *p);  // *p 表示"顺着 p 存的地址找到那个变量"，输出 10
```

### 1.2 指针和结构体的关系

```c
struct Patient {
    char name[50];
    int age;
    struct Patient* next;   // 存的是另一个 Patient 结构体的地址
};
```

- `struct Patient* p` → 这个指针 p 指向**某个 Patient 结构体实例**
- `p->name` 等价于 `(*p).name`，表示"顺着 p 找到那个结构体，再访问它的 name 字段"
- `p->next` 表示"这个结构体里的 next 指针，存的是下一个节点的地址"

### 1.3 野指针和空指针

```c
int* p;         // 未初始化，指针里是垃圾值 → 野指针（危险！）
int* p = NULL;  // 明确指向"空"，安全
```

- **野指针**：访问会崩溃或产生不可预料的后果
- **空指针**：访问前先判断 `if (p != NULL)` 即可安全处理
- **习惯**：malloc 后立即初始化所有字段；free 后立即置 NULL

### 1.4 二级指针：指向指针的指针

```c
int value = 42;
int* p1 = &value;      // p1 是普通指针，指向 value
int** p2 = &p1;        // p2 是二级指针，指向 p1（p1 本身就是个地址）
```

为什么要二级指针？—— **当你希望在一个函数内部修改外部的指针本身时**。

```c
// ❌ 错误：修改的是副本，外部的 head 指针不受影响
void initWrong(Patient* head) {
    head = (Patient*)malloc(sizeof(Patient));  // 只改了局部变量 head
}

// ✅ 正确：通过二级指针修改外部的 head 指针本身
void initCorrect(Patient** head, Patient** tail) {
    *head = NULL;   // 顺着 head 的地址，把外部的 head 设为 NULL
    *tail = NULL;
}
```

## 2. 双向链表结构解析

### 2.1 节点组成

每个节点包含两部分：

```
┌──────────────┬──────────────┬──────────────┐
│     pre      │     data     │     next     │
│  (前驱指针)   │   (数据域)    │  (后继指针)   │
└──────────────┴──────────────┴──────────────┘
       ↑                                    ↑
       │          双向链表                   │
       └────────────────────────────────────┘
```

- **data（数据域）**：存放实际数据（姓名、卡号、库存……）
- **next（后继指针）**：指向**下一个**节点，末尾节点的 next = NULL
- **pre（前驱指针）**：指向前一个节点，头节点的 pre = NULL

### 2.2 链表结构总览

```
head                                     tail
 │                                        │
 ▼                                        ▼
 NULL ◀──── pre ◀────┐           ┌──────▶ NULL
  ┌──────────────────────┐  ┌──────────────────────┐  ┌──────────────────────┐
  │  pre  │  data  │next│  │  pre  │  data  │next│  │  pre  │  data  │next│
  │ NULL  │  "张三" │ ──┼──│───────│  "李四" │ ──┼──│───────│  "王五" │ NULL│
  └───────┴─────────┴────┘  └───────┴─────────┴────┘  └───────┴─────────┴────┘
```

### 2.3 项目中的实际结构体

项目采用 **Data + Node 分离** 的设计模式，将数据域和指针域分开：

```c
// PatientData：纯数据域，不含指针
typedef struct PatientData {
    char cardNo[20];    // 门诊卡号
    char name[50];       // 姓名
    char gender[10];     // 性别
    char idCard[20];     // 身份证号
    char phone[15];      // 联系电话
    int  isActive;       // 住院状态（0=否，1=是）
} PatientData;

// Patient：链表节点，包裹数据 + 前后指针
typedef struct Patient {
    PatientData data;           // 数据部分
    struct Patient* next;      // 指向下一个节点
    struct Patient* pre;       // 指向前一个节点
} Patient;
```

这种分离设计的好处：
- 数据结构清晰，数据域和指针域职责分明
- 复制、传递数据时只需操作 `data`，不用动指针
- 在文件 I/O（保存/加载）时更方便

其他模块的结构体同理：`Doctor` / `MedicineNode` / `Registration` / `BedNode` 等。

## 3. 为什么要保存 head 和 tail 两个指针

### 3.1 head 的作用

从头节点出发，可以遍历**整个链表**。所有查询、遍历操作都以 head 为起点。

### 3.2 tail 的作用

有了 tail，**尾插法 O(1)** —— 直接把新节点接到 tail 后面，不用从头遍历到尾。

### 3.3 只保存 head 够不够？

够，但尾插需要 O(n) 遍历：

```c
// 只保存 head，尾插需要先走到末尾（O(n)）
Patient* cur = head;
while (cur->next != NULL) {
    cur = cur->next;   // 一直走到最后一个节点
}
// 现在 cur 是 tail，可以插入了
```

### 3.4 总结

| 操作 | 只需 head | 需要 head + tail |
|------|:---------:|:----------------:|
| 遍历整个链表 | ✅ | ✅ |
| 尾插法（添加节点） | ⚠️ O(n) 遍历 | ✅ O(1) |
| 尾删法（删除末尾） | ❌ 需要 pre | ✅ 直接用 tail |
| 判断空链表 | ✅ | ✅ |

项目中同时保存 `head` 和 `tail`，保证所有操作都是 O(1) 或 O(n) 的确定复杂度。

## 4. 什么时候用单指针、什么时候用双指针、什么时候用二级指针

这是最核心、最容易混淆的知识点，下面逐一讲解。

### 4.1 单指针：只读/遍历，不修改链表结构

**使用场景**：遍历、查找、打印——只顺着指针走，不改变节点之间的连接关系。

```c
// Patient* head：只读，不用改链表
void listAllPatients(Patient* head) {
    Patient* cur = head;        // 单指针 cur，从 head 开始
    while (cur != NULL) {       // 遍历
        printf("%s\n", cur->data.name);
        cur = cur->next;        // 单指针后移，只改变 cur 自己
    }
}
```

- `head` 本身不变，只是用 `cur` 变量去"走一遍"
- `cur = cur->next` 改变的是局部变量 `cur`，不影响外部的 `head`

**再例如**：
```c
// 单指针：查找节点（只读操作）
Patient* findPatientByCardNo(Patient* head, char* cardNo) {
    Patient* cur = head;        // cur 是遍历指针
    while (cur != NULL) {
        if (strcmp(cur->data.cardNo, cardNo) == 0) {
            return cur;         // 找到就返回
        }
        cur = cur->next;
    }
    return NULL;                // 遍历完没找到
}
```

### 4.2 双指针：同时操作两个节点（删除节点时）

**使用场景**：删除节点时，需要同时知道**当前节点**和**前一个节点**。

单向链表删除节点必须知道前驱，因为修改的是 `前驱->next`。
双向链表可以靠 `cur->pre` 直接找到前驱，但有时也需要**双指针**配合。

```c
// 场景：按姓名删除（单向遍历找节点，但删除需要知道前驱）
void delPatient(Patient** head, Patient** tail, char* name) {
    Patient* cur = *head;       // cur 指向当前检查的节点
    Patient* pre = NULL;        // pre 指向 cur 的前一个节点

    while (cur != NULL) {
        if (strcmp(cur->data.name, name) == 0) {
            // 找到目标，现在用 pre 和 cur 两个指针来修改连接
            if (pre == NULL) {
                // 情况2：删除头节点
                *head = cur->next;
                if (*head) (*head)->pre = NULL;
            } else {
                // 情况3/4：删除中间节点或尾节点
                pre->next = cur->next;
                if (cur->next) cur->next->pre = pre;
            }
            free(cur);
            return;
        }
        pre = cur;
        cur = cur->next;
    }
}
```

**双指针的核心作用**：
- `pre` 记住前一个节点
- `cur` 指向当前检查的节点
- 发现目标后，`pre->next` 跳过 `cur`，`cur->next->pre` 重新指回 `pre`

### 4.3 二级指针：修改外部的 head / tail 本身

**使用场景**：在函数内部**创建、修改、销毁链表本身**时（即改变 `head` 或 `tail` 的指向），需要传它们的地址。

```c
// ❌ 错误写法：函数内部申请的节点，外部根本收不到
void addPatientWrong(Patient* head, Patient* tail, PatientData d) {
    Patient* newNode = (Patient*)malloc(sizeof(Patient));
    newNode->data = d;
    newNode->next = newNode->pre = NULL;
    // tail 是局部副本，修改它外部不知道！
    tail->next = newNode;
    newNode->pre = tail;
    tail = newNode;  // 改了局部变量 tail，外部的 tail 还是旧的
}
```

```c
// ✅ 正确写法：传 head 和 tail 的地址（传二级指针）
void addPatientCorrect(Patient** head, Patient** tail, PatientData d) {
    Patient* newNode = (Patient*)malloc(sizeof(Patient));
    newNode->data = d;
    newNode->next = newNode->pre = NULL;

    if (*tail == NULL) {
        // 链表为空：新节点既是头也是尾
        *head = newNode;
        *tail = newNode;
    } else {
        // 链表非空：接到尾部
        (*tail)->next = newNode;
        newNode->pre = *tail;
        *tail = newNode;   // 修改了外部的 tail
    }
}
```

### 4.4 什么时候用哪种指针——速查表

| 操作类型 | 传参方式 | 典型示例 |
|----------|----------|----------|
| **遍历 / 查找**（不改链表） | `Type* head`（单指针） | `listAllPatients`、`findPatientByCardNo` |
| **修改链表结构**（头/尾/中间增删） | `Type** head, Type** tail`（二级指针） | `addPatient`、`delPatient`、`buildXxxChain` |
| **删除时需要前驱** | `Type* cur, Type* pre`（双指针配合） | `delPatient` 中遍历时同时维护 cur 和 pre |
| **只改节点内容，不改连接** | `Type* p`（单指针） | `modifyDoctor`、`incrementPatientCount` |
| **遍历中删除多个** | **特别注意**：先保存 next 再删 | 见第 10 节 |

### 4.5 一个容易错的点：函数参数是值传递

```c
void foo(Patient* head) {
    head = head->next;  // 改了局部变量 head，外部不变
}

// 调用：
Patient* myHead = ...;
foo(myHead);  // myHead 还是指向原头节点，没变
```

**记住**：C 语言里参数是"值传递"——把指针的值（地址）复制了一份进去。
想在函数里改 `head` 本身（改它指向谁），必须传 `&head`，即二级指针。

## 5. 初始化链表

### 5.1 目标

将 `head` 和 `tail` 都设为 NULL，表示"空链表"。

### 5.2 为什么需要初始化函数？

`head` 和 `tail` 是**全局变量**或**局部 static 变量**：
- 全局变量自动初始化为 0（NULL）
- 但在程序运行时，链表可能已经被 `freeXxxChain` 释放，需要重新归零
- 显式初始化函数让逻辑更清晰，也便于以后扩展（如设置哨兵节点）

### 5.3 代码实现

```c
// patient.h
void initPatientChain(Patient** head, Patient** tail) {
    *head = NULL;
    *tail = NULL;
}
```

调用处：
```c
int main() {
    Patient* g_patientHead = NULL;
    Patient* g_patientTail = NULL;
    initPatientChain(&g_patientHead, &g_patientTail);
    return 0;
}
```

### 5.4 初始化 vs 清空

| 函数 | 作用 | 之后链表状态 |
|------|------|-------------|
| `initXxxChain` | 只把 head/tail 置 NULL | 空链表（节点已全部释放） |
| `freeXxxChain` | 遍历 free 所有节点 | 节点没了，但 head/tail 还指向原地址（野指针！） |
| `freeXxxChain` + `initXxxChain` | 释放节点 + 重置指针 | 完全干净的空链表 |

> 最佳实践：`freeXxxChain` 的最后一行加上 `*head = NULL; *tail = NULL;`，这样就不需要单独调用 init 了。

## 6. 创建节点（malloc + 初始化）

### 6.1 三步走

```c
// 第一步：malloc 分配内存
Patient* newNode = (Patient*)malloc(sizeof(Patient));

// 第二步：检查是否分配成功（防御性编程）
if (newNode == NULL) {
    printf("内存分配失败！\n");
    return;
}

// 第三步：初始化新节点的所有字段
newNode->next = NULL;          // 后继指针
newNode->pre  = NULL;          // 前驱指针
// data 部分由调用者填充，或在这里设置默认值
```

### 6.2 完整示例

```c
Patient* createPatientNode(char* name, char* gender, char* idCard, char* phone) {
    Patient* node = (Patient*)malloc(sizeof(Patient));
    if (!node) return NULL;

    // 初始化指针
    node->next = NULL;
    node->pre  = NULL;

    // 填充数据
    strcpy(node->data.name, name);
    strcpy(node->data.gender, gender);
    strcpy(node->data.idCard, idCard);
    strcpy(node->data.phone, phone);
    node->data.isActive = 0;   // 初始不住院

    // 生成唯一卡号（调用工具函数）
    char id[20];
    generateUniqueId("PT", id);
    strcpy(node->data.cardNo, "PT");
    strcat(node->data.cardNo, id);

    return node;
}
```

### 6.3 常见错误

```c
// ❌ 错误1：malloc 后不检查
Patient* node = malloc(sizeof(Patient));  // 缺少 (Patient*)，C 可以但不好
if (node == NULL) ...  // ❌ 忘记检查

// ❌ 错误2：sizeof 里写错类型
Patient* node = malloc(sizeof(PatientData));  // ❌ 只分配了数据域大小！
// 正确：sizeof(Patient)

// ❌ 错误3：字符串赋值用 =
strcpy(node->data.name, name);   // ✅ 用 strcpy
node->data.name = name;          // ❌ 不能用 = 直接赋值数组
```

## 7. 尾插法：添加节点到链表尾部

### 7.1 什么是尾插法？

每次把新节点插入到链表**末尾**。新来的排在后面，先来的排在前面。

### 7.2 两种情况

#### 情况 A：链表为空（head == NULL && tail == NULL）

```c
*head = newNode;
*tail = newNode;
// newNode 的 next 和 pre 已经是 NULL，不用改
```

#### 情况 B：链表非空

```c
(*tail)->next = newNode;    // 旧尾巴的 next 指向新节点
newNode->pre  = *tail;      // 新节点的 pre 指回旧尾巴
*tail = newNode;            // 更新 tail 指向新节点
```

### 7.3 完整代码

```c
void addPatient(Patient** head, Patient** tail, PatientData d) {
    Patient* newNode = (Patient*)malloc(sizeof(Patient));
    if (!newNode) return;

    newNode->data = d;       // 整个 data 复制过来
    newNode->next = NULL;
    newNode->pre  = NULL;

    if (*tail == NULL) {
        // 链表为空
        *head = newNode;
        *tail = newNode;
    } else {
        // 链表非空，接到尾巴
        (*tail)->next = newNode;
        newNode->pre  = *tail;
        *tail = newNode;
    }
}
```

### 7.4 图解尾插全过程

**插入第一个节点前**（空链表）：
```
head = NULL, tail = NULL
```

**插入第一个节点 node1 后**：
```
head ──► [node1(data, NULL, NULL)] ◄── tail
```

**插入第二个节点 node2 后**：
```
head ──► [node1(data, NULL, node2)] ◄──► [node2(data, node1, NULL)] ◄── tail
```

**插入第三个节点 node3 后**：
```
head ──► [n1(data, NULL, n2)] ◄──► [n2(data, n1, n3)] ◄──► [n3(data, n2, NULL)] ◄── tail
```

### 7.5 头插法（了解即可，项目不用）

头插法每次把新节点插到**最前面**：
```c
newNode->next = *head;
if (*head) (*head)->pre = newNode;
*head = newNode;
// 链表为空时 head==tail==NULL，(*head)->pre 会崩溃，所以要判断
```
> 项目选择尾插法，因为医院系统中一般按添加顺序记录（先来的病人先处理），头插法会颠倒顺序。

## 8. 遍历链表

### 8.1 基本遍历（单指针）

从头走到尾，访问每个节点。

```c
void listAllPatients(Patient* head) {
    if (head == NULL) {
        printf("暂无病人记录。\n");
        return;
    }

    Patient* cur = head;          // 单指针 cur，从 head 开始
    int count = 0;

    while (cur != NULL) {          // 结束条件：cur 到达 NULL（链表末尾之后）
        count++;
        printf("=== 病人 %d ===\n", count);
        printf("  卡号：%s\n", cur->data.cardNo);
        printf("  姓名：%s\n", cur->data.name);
        printf("  性别：%s\n", cur->data.gender);
        printf("  状态：%s\n", cur->data.isActive ? "住院中" : "未住院");
        printf("\n");
        cur = cur->next;           // 关键！指针后移
    }
    printf("共 %d 条记录。\n", count);
}
```

**关键点**：
- 结束条件是 `cur != NULL`，不是 `cur->next != NULL`（后者会漏掉最后一个节点）
- 循环内部 `cur = cur->next` 不要漏，否则死循环

### 8.2 反向遍历（从 tail 向 head）

双向链表独有的能力！

```c
void listAllPatientsReverse(Patient* tail) {
    if (tail == NULL) {
        printf("链表为空。\n");
        return;
    }

    Patient* cur = tail;          // 从尾巴开始
    while (cur != NULL) {
        printf("%s\n", cur->data.name);
        cur = cur->pre;            // 向后遍历是 next，向前是 pre
    }
}
```

### 8.3 遍历中计数（统计）

```c
int countPatients(Patient* head) {
```

## 10. 删除节点：四种情况详解

### 10.1 删除节点的本质

删除节点 `p` 只需要两步：
1. 让 `p` 的前一个节点指向 `p` 的后一个节点
2. 让 `p` 的后一个节点指向 `p` 的前一个节点（如果有的话）
3. `free(p)`

双向链表的优势在这里体现出来了：第 2 步靠 `p->next->pre = p->pre` 即可，不需要像单向链表那样必须传入前驱指针。

### 10.2 四种情况图解

假设链表有 3 个节点（A、B、C），讨论删除 B：

```
情况1：A-B-C，删除B（中间节点）
删除前：A <--> B <--> C
  A->next = C
  C->pre = A
  free(B)
删除后：A <--> C ✓

情况2：A-B，删除A（头节点，且是唯一节点）
删除前：A <--> B（head=A, tail=B）
  *head = B
  B->pre = NULL
  free(A)
删除后：B（head=tail=B）✓

情况3：A-B，删除B（尾节点）
删除前：A <--> B（head=A, tail=B）
  A->next = NULL
  *tail = A
  free(B)
删除后：A（head=tail=A）✓

情况4：A（只有一个节点），删除A
删除前：head=tail=A
  *head = NULL
  *tail = NULL
  free(A)
删除后：空链表 ✓
```

### 10.3 完整代码（双指针遍历 + 四种情况分支）

```c
void delPatient(Patient** head, Patient** tail, char* cardNo) {
    if (*head == NULL) {
        printf("链表为空，无法删除。\n");
        return;
    }

    // 第一步：找到目标节点（同时记住前驱）
    Patient* cur = *head;
    Patient* pre = NULL;

    while (cur != NULL) {
        if (strcmp(cur->data.cardNo, cardNo) == 0) {
            break;                    // 找到了，跳出循环
        }
        pre = cur;                    // 先更新 pre
        cur = cur->next;              // 再移动 cur
    }

    if (cur == NULL) {
        printf("未找到该病人，无法删除。\n");
        return;
    }

    // 第二步：分四种情况处理
    if (cur == *head && cur == *tail) {
        // 情况1：链表只有一个节点（head == tail）
        *head = NULL;
        *tail = NULL;
    } else if (cur == *head) {
        // 情况2：删除头节点
        *head = cur->next;
        (*head)->pre = NULL;         // 新头节点的 pre 必须是 NULL
    } else if (cur == *tail) {
        // 情况3：删除尾节点
        *tail = pre;                  // tail 指向前一个
        (*tail)->next = NULL;        // 新尾巴的 next 是 NULL
    } else {
        // 情况4：删除中间节点
        pre->next = cur->next;        // 前节点的 next 跳过 cur
        cur->next->pre = pre;         // 后节点的 pre 指回前节点
    }

    // 第三步：释放内存
    free(cur);
    printf("删除成功。\n");
}
```

### 10.4 删除时的常见错误

```c
// ❌ 错误1：先 free 再改指针（use-after-free）
pre->next = cur->next;    // 此时 cur->next 可能还有用，但已经在前面了
cur->next->pre = pre;
free(cur);                // 顺序OK，但要注意不要在 free 后访问 cur

// ❌ 错误2：忘记更新 tail
// 只改了 head 没改 tail，导致 tail 仍指向已释放的节点（野指针！）

// ❌ 错误3：忘记判断 cur->next 是否为 NULL
cur->next->pre = pre;     // 如果 cur 是尾节点，cur->next == NULL，
                           // 这里访问 NULL->pre 会崩溃

// ✅ 正确做法：先判断
if (cur->next != NULL) {
    cur->next->pre = pre;
}
```

### 10.5 遍历中删除多个节点（特别注意）

如果在遍历过程中**删除**节点，**必须先保存下一个节点的地址**：

```c
// ❌ 错误：cur 被 free 后，cur->next 无法访问
Patient* cur = head;
while (cur != NULL) {
    if (shouldDelete(cur)) {
        Patient* toDelete = cur;
        cur = cur->next;   // ❌ toDelete 就是 cur，此时 cur 已标记要删
        free(toDelete);
        // 错误：此时 cur 可能已经是野指针
    }
    cur = cur->next;
}
```

```c
// ✅ 正确：先保存 next，再删
Patient* cur = head;
while (cur != NULL) {
    Patient* next = cur->next;   // 先把下一个存起来！

    if (shouldDelete(cur)) {
        // 从链表中摘除
        if (cur->pre) cur->pre->next = cur->next;
        if (cur->next) cur->next->pre = cur->pre;
        if (cur == head) head = cur->next;
        if (cur == tail) tail = cur->pre;
        free(cur);
    }

    cur = next;   // 用之前保存的 next 继续遍历（安全！）
}
```

## 11. 释放整个链表

### 11.1 核心思路

从头开始，逐个释放。每释放一个节点之前，先把**下一个节点的地址**保存下来（因为 free 后就无法访问 `node->next` 了）。

### 11.2 代码实现

```c
void freePatientChain(Patient** head, Patient** tail) {
    Patient* cur = *head;
    while (cur != NULL) {
        Patient* next = cur->next;   // 先保存下一个节点的地址
        free(cur);                    // 释放当前节点
        cur = next;                   // 移动到下一个
    }
    *head = NULL;                     // 重要！防止野指针
    *tail = NULL;                     // 重要！
}
```

**三行关键代码的顺序**：
1. `next = cur->next` —— 保存后路
2. `free(cur)` —— 释放当前
3. `cur = next` —— 走向后路

### 11.3 内存布局变化图解

```
释放前：head ──► [A] ◄──► [B] ◄──► [C] ◄── tail ──► NULL
        cur=A, next=B

第1次循环：free(A)，cur=B
          head ──► [B] ◄──► [C] ◄── tail ──► NULL

第2次循环：free(B)，cur=C
          head ──► [C] ◄── tail ──► NULL

第3次循环：free(C)，cur=NULL，退出循环
          head=NULL, tail=NULL
```

### 11.4 释放时的注意事项

```c
// ❌ 错误1：忘记保存 next
while (cur != NULL) {
    free(cur);       // free 后无法再访问 cur->next！
    cur = cur->next; // ❌ 野指针
}

// ❌ 错误2：释放后不置 NULL
freePatientChain(&head, &tail);
// head 和 tail 仍指向原地址，但那块内存已经无效了
// 后续代码若再访问会崩溃
// ✅ 必须在函数末尾加上 *head = *tail = NULL
```

## 12. 从头文件加载链表（buildXxxChain）

### 12.1 整体流程

```
文件内容：
1
PT001
张三
男
...
1
PT002
李四
...
-1

  │
  ▼
逐行读取 → fscanf → 分配节点 → 尾插到链表 → 更新 pre 指针
  │
  ▼
关闭文件，head 和 tail 已正确指向链表
```

### 12.2 为什么需要 buildXxxChain？

程序每次启动时，数据从文件加载到内存（链表）。关闭时，从链表保存回文件。
如果不加载，程序重启后所有数据就丢失了。

### 12.3 代码实现（以病人为例）

```c
void buildPatientChain(Patient** head, Patient** tail) {
    FILE* fp = fopen(PATIENT_FILE, "r");

    if (fp == NULL) {
        // 文件不存在，创建空文件
        fp = fopen(PATIENT_FILE, "w");
        if (fp) {
            fprintf(fp, "-1\n");
            fclose(fp);
        }
        *head = NULL;
        *tail = NULL;
        return;
    }

    Patient* pre = NULL;   // 跟踪上一个节点，用于设置 pre 指针

    while (1) {
        int opt;
        fscanf(fp, "%d", &opt);    // 读入标记

        if (opt == -1) {
            break;                  // 读到 -1，文件结束
        }

        if (opt == 1) {
            // 读到 1，开始读一条记录
            Patient* node = (Patient*)malloc(sizeof(Patient));
            node->next = NULL;
            node->pre  = NULL;

            // 依次读入各字段（按 patient.txt 文件格式）
            fscanf(fp, "%s", node->data.cardNo);
            fscanf(fp, "%s", node->data.name);
            fscanf(fp, "%s", node->data.gender);
            fscanf(fp, "%s", node->data.idCard);
            fscanf(fp, "%s", node->data.phone);
            fscanf(fp, "%d", &node->data.isActive);

            // 尾插法插入链表
            if (*head == NULL) {
                *head = node;      // 第一个节点：同时作为 head 和 tail
            } else {
                pre->next = node;  // 前一个节点的 next 指向新节点
                node->pre = pre;   // 新节点的 pre 指回前一个
            }
            pre = node;            // 更新 pre 指向当前节点
            *tail = pre;           // 更新 tail 始终指向最后一个节点
        }
    }

    fclose(fp);                     // 关闭文件
}
```

**关键点解析**：
- `pre` 变量在循环外初始化为 NULL，随着循环推进始终指向"上一个已读入的节点"
- 每读入一条新记录，就用 `pre->next = node; node->pre = pre` 把节点串进链表
- 循环结束后 `*tail = pre`，因为 `pre` 此时指向最后读入的节点
- 如果文件不存在（fp==NULL），先创建空文件并写入 `-1`，避免下次启动时文件仍不存在

### 12.4 通用 buildXxxChain 模板

所有模块的 `buildXxxChain` 都遵循同一套模板，只是字段数量和文件名不同：

```c
// 通用模板（以 Medicine 为例）
void buildMedicineChain(MedicineNode** head, MedicineNode** tail) {
    FILE* fp = fopen(MEDICINE_FILE, "r");
    if (fp == NULL) {
        fp = fopen(MEDICINE_FILE, "w");
        if (fp) { fprintf(fp, "-1\n"); fclose(fp); }
        *head = NULL; *tail = NULL; return;
    }

    MedicineNode* pre = NULL;
    while (1) {
        int opt; fscanf(fp, "%d", &opt);
        if (opt == -1) break;
        if (opt == 1) {
            MedicineNode* node = (MedicineNode*)malloc(sizeof(MedicineNode));
            node->next = NULL; node->pre = NULL;
            // 读字段（字段数量因模块而异）
            fscanf(fp, "%s", node->data.medNo);
            fscanf(fp, "%s", node->data.genericName);
            fscanf(fp, "%s", node->data.brandName);
            fscanf(fp, "%s", node->data.spec);
            fscanf(fp, "%lf", &node->data.price);
            fscanf(fp, "%d", &node->data.stock);
            fscanf(fp, "%d", &node->data.minStock);
            // 插入链表
            if (*head == NULL) { *head = node; }
            else { pre->next = node; node->pre = pre; }
            pre = node; *tail = pre;
        }
    }
    fclose(fp);
}
```

## 13. 保存链表到文件（rebuildXxxFile）

### 13.1 整体流程

```
内存链表：head ──► [A] ◄──► [B] ◄──► [C] ◄── tail

遍历链表：
  每遇到一个节点 → fprintf 写入 "1\n" + 各字段 + "\n"
  末尾 → fprintf 写入 "-1\n"

文件内容：
  1
  PT001
  张三
  男
  ...
  1
  PT002
  李四
  ...
  -1
```

### 13.2 为什么用 "w" 模式？

`fopen(filename, "w")` 会**先清空原文件**，保证每次保存都是完整的最新的数据。

### 13.3 代码实现（以病人为例）

```c
void rebuildPatientFile(Patient* head) {
    FILE* fp = fopen(PATIENT_FILE, "w");
    if (fp == NULL) {
        printf("保存失败：无法打开文件 %s\n", PATIENT_FILE);
        return;
    }

    Patient* cur = head;
    while (cur != NULL) {
        fprintf(fp, "1\n");                              // 有效记录标记
        fprintf(fp, "%s\n", cur->data.cardNo);           // 依次写入所有字段
        fprintf(fp, "%s\n", cur->data.name);
        fprintf(fp, "%s\n", cur->data.gender);
        fprintf(fp, "%s\n", cur->data.idCard);
        fprintf(fp, "%s\n", cur->data.phone);
        fprintf(fp, "%d\n", cur->data.isActive);
        fprintf(fp, "\n");                                // 记录之间留空行
        cur = cur->next;
    }
    fprintf(fp, "-1\n");                                  // 结束标记
    fclose(fp);
}
```

**注意**：`rebuildPatientFile` 和 `rebuildDoctorFile` 在团队头文件里的参数是**值传递**（`Patient head`，不是 `Patient* head`），这是因为保存操作不需要修改链表本身，只需要顺着 head 遍历。

### 13.4 通用 rebuildXxxFile 模板

```c
// 通用模板（以 Medicine 为例）
void rebuildMedicineFile(MedicineNode* head) {
    FILE* fp = fopen(MEDICINE_FILE, "w");
    if (!fp) return;
    MedicineNode* cur = head;
    while (cur != NULL) {
        fprintf(fp, "1\n");
        fprintf(fp, "%s\n",   cur->data.medNo);
        fprintf(fp, "%s\n",  cur->data.genericName);
        fprintf(fp, "%s\n",  cur->data.brandName);
        fprintf(fp, "%s\n",  cur->data.spec);
        fprintf(fp, "%.2f\n", cur->data.price);
        fprintf(fp, "%d\n",  cur->data.stock);
        fprintf(fp, "%d\n",  cur->data.minStock);
        fprintf(fp, "\n");
        cur = cur->next;
    }
    fprintf(fp, "-1\n");
    fclose(fp);
}
```

### 13.5 为什么用标记而不是直接读写字段？

文件格式使用 `1`/`-1` 标记而不是直接逐行写字段的原因：

| 方式 | 优点 | 缺点 |
|------|------|------|
| `1`/`-1` 标记 | 灵活性高，可以跳过/跳过损坏行；空行自然分隔 | 格式稍复杂 |
| 纯字段逐行 | 简单 | 如果某行损坏，后续全部错位；无法区分空文件和纯数据 |

> 项目采用 `1`/`-1` 标记格式，即便某条记录中间出错，读到下一个 `1` 或 `-1` 就能恢复正常。

## 15. 常见错误与调试技巧

### 15.1 野指针（Use After Free）

```c
// ❌ 错误：释放后继续使用
Patient* p = findPatientByCardNo(head, "PT001");
freePatientChain(&head, &tail);
printf("%s", p->data.name);  // ❌ p 已成野指针，程序可能崩溃
```

### 15.2 循环链表（死循环）

```c
// ❌ 错误：尾节点 next 没有设为 NULL → 死循环
while (cur != NULL) {
    // ... 漏掉了 cur->next = NULL 的设置
    cur = cur->next;  // 永远不会到达 NULL
}
```

### 15.3 内存泄漏

```c
// ❌ 错误：每次 add 都 malloc 但从不 free
void addDoctor(...) {
    Doctor* d = (Doctor*)malloc(sizeof(Doctor));
    // ... 添加到链表
    // 函数结束，d 指针变量销毁，但 malloc 的内存还在堆里
}
// 正确做法：程序结束时调用 freeDoctorChain 统一释放
```

### 15.4 调试技巧

**技巧 1：打印链表结构（验证指针连接）**

```c
void debugPrintChain(Patient* head) {
    printf("=== 链表调试 ===\n");
    printf("正向遍历：\n");
    Patient* cur = head;
    int i = 0;
    while (cur != NULL) {
        printf("  [%d] name=%s, pre=%p, next=%p\n",
            i++, cur->data.name, (void*)cur->pre, (void*)cur->next);
        cur = cur->next;
    }
    printf("共 %d 个节点\n\n", i);
}
```

```c
// ❌ 错误：混用 head 和 tail 判断
```
