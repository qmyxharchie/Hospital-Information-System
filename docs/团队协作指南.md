## 八、必须掌握的新知识详解

### 8.1 双向链表（比单向多一个 `pre` 指针）

**你们的 scoresystem 用的是单向链表**：
```c
typedef struct node {
    Student data;
    struct node *next;      // 只能往后找
} Node;
```

**医院项目用的是双向链表**：
```c
typedef struct Patient {
    char cardNo[20];
    char name[50];
    // ...其他字段
    struct Patient *next;   // 往后找
    struct Patient *pre;    // 👈 多这个，往前找
} Patient;
```

**区别只有两处**：
- 定义时多一个 `pre` 指针
- 删除节点时多一步：`p->pre->next = p->next`（让前一个节点跳过当前节点）

### 8.2 文件格式（多了标记位）

**scoresystem 的格式**（每行一个字段）：
```
1 张三 90 80 70 60 50
2 李四 85 90 88 92 91
```

**医院项目的格式**（带标记位）：
```
1                              ← 1 = 这条记录有效
PT20260407142530               ← 卡号
张三                           ← 姓名
男                             ← 性别
220102199001011234              ← 身份证
13800138000                    ← 电话
0                              ← 住院状态（0=否，1=是）

1                              ← 下一条记录
PT20260407142531
李四
女
...

-1                             ← -1 = 文件结束
```

**读取逻辑**：
```c
while (1) {
    int opt;
    fscanf(fp, "%d", &opt);
    if (opt == -1) break;      // 读到 -1 就停止
    if (opt == 1) {
        // 读一条完整记录
        fscanf(fp, "%s", now->cardNo);
        fscanf(fp, "%s", now->name);
        // ...
    }
}
```

### 8.3 MD5 调用（不需要会写原理）

**只需要会这一行调用**：
```c
char hashed[100];
md5Hash(password, hashed);   // 把密码加密成哈希值存到 hashed 里
```

### 8.4 模块间调用（挂号模块需要）

挂号需要同时用病人模块和医生模块的数据：
```c
// registration.c 中
int addRegistration(...) {
    // 1. 检查病人是否存在（调用 patient 模块）
    Patient* p = findPatientByCardNo(g_patientHead, patientCardNo);
    if (p == NULL) { printf("病人不存在"); return 0; }

    // 2. 检查医生是否还有名额（调用 doctor 模块）
    Doctor* d = findDoctorByEmpNo(g_doctorHead, doctorEmpNo);
    if (d->currentPatients >= d->maxPatients) { printf("医生已满号"); return 0; }

    // 3. 创建挂号记录
    // ...

    // 4. 挂号成功，医生今日接诊数 +1
    d->currentPatients++;
}
```
