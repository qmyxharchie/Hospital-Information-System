## 1. 唯一ID生成

### 1.1 功能

生成唯一的ID字符串，用于：
- 病人卡号
- 医生工号
- 挂号单号
- 药品编号
- 住院单号

### 1.2 实现

```c
char* generateUniqueId() {
    static int counter = 0;
    static char id[50];
    
    time_t now = time(NULL);
    struct tm* t = localtime(&now);
    
    counter++;  // 递增计数器，防止同一秒内多次生成
    
    sprintf(id, "%04d%02d%02d%02d%02d%02d%02d",
            t->tm_year + 1900,
            t->tm_mon + 1,
            t->tm_mday,
            t->tm_hour,
            t->tm_min,
            t->tm_sec,
            counter % 100);  // 保证同一秒内的唯一性
    
    return id;
}
```

### 1.3 使用示例

```c
// 生成病人卡号
Patient* p = (Patient*)malloc(sizeof(Patient));
sprintf(p->cardNo, "PT%s", generateUniqueId());
// 结果：PT2026040714304501
```

## 2. 时间处理

### 2.1 获取当前时间

```c
void getCurrentTime(char* buffer, int size) {
    time_t now = time(NULL);
    struct tm* t = localtime(&now);
    strftime(buffer, size, "%Y-%m-%d %H:%M:%S", t);
}
```

### 2.2 获取日期字符串

```c
void getCurrentDate(char* buffer, int size) {
    time_t now = time(NULL);
    struct tm* t = localtime(&now);
    strftime(buffer, size, "%Y-%m-%d", t);
}
```

## 3. 字符串处理

### 3.1 安全字符串复制

```c
void safeStringCopy(char* dest, const char* src, int maxLen) {
    if (src == NULL) {
        dest[0] = '\0';
        return;
    }
    
    strncpy(dest, src, maxLen - 1);
    dest[maxLen - 1] = '\0';  // 确保字符串以\0结尾
}
```

### 3.2 去除空白字符

```c
char* trim(char* str) {
    char* start = str;
    char* end;
    
    // 去除开头空白
    while (*start == ' ' || *start == '\t' || *start == '\n') {
        start++;
    }
    
    // 去除结尾空白
    end = start + strlen(start) - 1;
    while (end > start && (*end == ' ' || *end == '\t' || *end == '\n')) {
        end--;
    }
    *(end + 1) = '\0';
    
    // 移动字符串
    if (start != str) {
        memmove(str, start, strlen(start) + 1);
    }
    
    return str;
}
```

## 4. 输入验证

### 4.1 手机号验证

```c
int isValidPhone(const char* phone) {
    if (phone == NULL) return 0;
    if (strlen(phone) != 11) return 0;
    
    for (int i = 0; i < 11; i++) {
        if (!isdigit(phone[i])) return 0;
    }
    
    return 1;
}
```

### 4.2 身份证验证

```c
int isValidIdCard(const char* idCard) {
    if (idCard == NULL) return 0;
    if (strlen(idCard) != 18) return 0;
    
    // 检查前17位是否为数字
    for (int i = 0; i < 17; i++) {
        if (!isdigit(idCard[i])) return 0;
    }
    
    // 检查第18位是否为数字或X
    char last = idCard[17];
    if (!isdigit(last) && last != 'X' && last != 'x') return 0;
    
    return 1;
}
```

### 4.3 日期验证

```c
int isValidDate(const char* date) {
    if (date == NULL) return 0;
    if (strlen(date) != 10) return 0;
    
    int year, month, day;
    if (sscanf(date, "%d-%d-%d", &year, &month, &day) != 3) return 0;
    
    if (year < 1900 || year > 2100) return 0;
    if (month < 1 || month > 12) return 0;
    if (day < 1 || day > 31) return 0;
    
    return 1;
}
```
