## 1. 模块概述

### 1.1 功能描述

主程序入口模块（main.c）负责整个医院信息管理系统的启动和流程控制，包括系统初始化、用户登录验证、菜单导航、权限控制和系统退出等功能。

### 1.2 主程序与其他模块的关系

```
┌─────────────────────────────────────────────────────┐
│              main.c (主程序入口)                   │
│  - 系统初始化                                     │
│  - 用户登录验证                                   │
│  - 菜单导航控制                                   │
│  - 权限管理                                       │
│  - 系统退出处理                                   │
└─────────────────────────────────────────────────────┬─
                   │ 调用各模块函数
                   │
┌─────────────────────────────────────────────────────┬─
│              各业务模块 (patient.c、doctor.c等)       │
│  - 实现具体业务逻辑                                │
│  - 提供函数接口                                    │
└─────────────────────────────────────────────────────┬─
                   │ 调用文件读写函数
                   │
┌─────────────────────────────────────────────────────┐
│              数据持久化 (file_io.c)                │
│  - 从 data/*.txt 读入链表                          │
│  - 从链表写入 data/*.txt                           │
└─────────────────────────────────────────────────────┘
```

## 4. 主函数实现指南

### 4.1 创建步骤

**步骤1**：实现main函数主体
- 调用系统初始化
- 显示系统欢迎信息
- 进入主循环

**步骤2**：实现主循环逻辑
- 显示登录界面
- 验证用户登录
- 根据用户类型显示不同菜单

### 4.2 主函数实现思路

```c
// 主函数示例格式
int main(void) {
    // 初始化系统
    if (!initSystem()) {
        printf("系统初始化失败，按任意键退出...\n");
        system("pause");
        return -1;
    }
    
    printf("\n=====================================\n");
    printf("      欢迎使用医院信息管理系统\n");
    printf("=====================================\n\n");
    
    // 主循环
    int loginStatus;
    do {
        // 显示登录界面（调用UI模块函数，如已创建）
        // loginStatus = showLoginPage();  // 在UI教程完成后调用
        
        // 临时使用控制台登录
        loginStatus = consoleLogin();
        
        switch(loginStatus) {
            case LOGIN_SUCCESS_ADMIN:
                g_currentUserType = 1;
                adminMenu();
                break;
            case LOGIN_SUCCESS_USER:
                g_currentUserType = 2;
                patientMenu();
                break;
            case LOGIN_EXIT:
                printf("感谢使用医院信息管理系统！\n");
                break;
            default:
                printf("登录失败，请重试。\n");
                break;
        }
    } while(loginStatus != LOGIN_EXIT);
    
    // 退出系统
    exitSystem();
    
    return 0;
}
```

**实现提示**：
- 主循环要处理退出状态
- 用户类型要正确设置
- 退出时要清理资源

**步骤2**：实现用户菜单函数

### 5.2 控制台登录实现思路

```c
// 控制台登录函数示例格式
int consoleLogin(void) {
    char username[50];
    char password[50];
    int userType;
    
    printf("\n========== 用户登录 ==========\n");
    printf("请选择登录类型:\n");
    printf("1. 管理员登录\n");
    printf("2. 普通用户登录\n");
    printf("0. 退出系统\n");
    printf("请选择: ");
    
    scanf("%d", &userType);
    getchar(); // 清除换行符
    
    if (userType == 0) {
        return LOGIN_EXIT;
    }
    
    if (userType != 1 && userType != 2) {
        printf("无效的选择！\n");
        return LOGIN_FAILED;
    }
    
    printf("请输入用户名: ");
    scanf("%s", username);
    printf("请输入密码: ");
    scanf("%s", password);
    
    // 验证登录
    if (verifyLogin(username, password, userType == 1)) {
        strcpy(g_currentUserId, username);
        printf("登录成功！\n");
        return (userType == 1) ? LOGIN_SUCCESS_ADMIN : LOGIN_SUCCESS_USER;
    } else {
        printf("用户名或密码错误！\n");
        return LOGIN_FAILED;
    }
}
```

**实现提示**：
- 输入处理要考虑缓冲区清理
- 用户名密码验证要安全
- 登录状态返回要准确
