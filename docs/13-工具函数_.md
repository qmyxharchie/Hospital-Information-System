## 1. 模块概述

工具函数是项目中所有模块共享的底层辅助函数，包括：
- 时间处理
- 字符串处理
- 输入验证
- 全局时间状态

这些函数被所有业务模块（patient.c、doctor.c、registration.c 等）频繁调用，属于基础设施层。

## 2. 全局变量

```c
// utils.h
extern int g_currentYear;   // 系统当前年份
extern int g_currentMonth;  // 系统当前月份
extern int g_currentDay;    // 系统当前日期
```

**作用**：其他模块需要获取当前日期时，直接读取这三个全局变量，而不需要每次调用 `time()` 系统函数，效率更高。

## 3. 时间处理函数

> **统一格式**：`[返回类型] 函数名(...)` — 所属头文件

### 3.1 获取当前日期

```c
// utils.h
void getCurrentTime(int* year, int* month, int* day);
```

**实现思路**：
1. **第1步**：调用 `time(NULL)` 获取当前时间戳
2. **第2步**：调用 `localtime()` 将时间戳转换为 `struct tm` 结构体
3. **第3步**：`*year = t->tm_year + 1900`（struct tm 的年份从 1900 年算起）
4. **第4步**：`*month = t->tm_mon + 1`（struct tm 的月份从 0 开始）
5. **第5步**：`*day = t->tm_mday`

**⚠️ 注意**：这里**不是** `char* buffer`，而是三个 `int*` 输出参数！这是团队版本的重大改动。

**调用示例**：
```c
int y, m, d;
getCurrentTime(&y, &m, &d);
printf("今天是 %d-%02d-%02d\n", y, m, d);
// 输出：今天是 2026-04-11
```

### 3.2 生成唯一ID

```c
// utils.h
void generateUniqueId(const char* prefix, char* id);
```

**参数说明**：
- `prefix`：前缀字符串，如 `"PT"`、`"DOC"`、`"REG"`、`"MED"`、`"HOS"`
- `id`：预分配至少 20 字节的字符数组，函数内部填充结果

**实现思路**：
1. **第1步**：调用 `time(NULL)` 获取当前时间戳
2. **第2步**：调用 `localtime()` 转换为 `struct tm`
3. **第3步**：用 `sprintf(id, "%s%04d%02d%02d%02d%02d%02d", prefix, year, month, day, hour, min, sec)` 拼接字符串
4. **第4步**：使用静态计数器 `static int counter` 避免同一秒内多次调用产生重复 ID
5. **第5步**：最后拼接计数器值，保证唯一性

**⚠️ 注意**：返回类型是 **`void`**，不是 `char*`！返回值通过第二个参数 `id` 输出。

**调用示例**：
```c
char id[20];
generateUniqueId("PT", id);   // 生成病人卡号
// 结果：PT20260411192030

generateUniqueId("DOC", id);  // 生成医生工号
// 结果：DOC20260411192030
```

### 3.3 比较两个日期

```c
// utils.h
int compareDate(int year1, int month1, int day1,
                int year2, int month2, int day2);
```

**返回值**：
- `0`：两个日期相同
- 负数：日期1 < 日期2
- 正数：日期1 > 日期2

**实现思路**（从年到日逐级比较）：
1. **第1步**：比较 `year1` 和 `year2`，不同则直接返回差值
2. **第2步**：比较 `month1` 和 `month2`，不同则返回差值
3. **第3步**：返回 `day1 - day2`

**调用示例**：
```c
int result = compareDate(2026, 4, 10, 2026, 4, 11);
// result < 0 → 日期1在日期2之前
```

## 4. 字符串处理函数

### 4.1 安全字符串复制

```c
// utils.h
void safeStringCopy(char* dest, const char* src, int maxLen);
```

**作用**：防止缓冲区溢出，比直接用 `strcpy` 更安全。

**实现思路**：
1. **第1步**：如果 `src == NULL`，`dest[0] = '\0'`，直接返回
2. **第2步**：调用 `strncpy(dest, src, maxLen - 1)` 最多复制 maxLen-1 个字符
3. **第3步**：显式设置 `dest[maxLen - 1] = '\0'` 确保结尾
4. **第4步**：返回

---

### 4.2 去除两端空白字符

```c
// utils.h
void trim(char* str);
```

**实现思路**：
1. **第1步**：用指针 `start` 指向字符串开头，跳过开头的空格、Tab、换行符
2. **第2步**：用指针 `end` 指向字符串末尾，向前跳过末尾的空白字符
3. **第3步**：将处理后的字符串移动到原字符串开头位置（`memmove`）
4. **第4步**：在结尾加上 `'\0'`

**注意**：对 `char date[20]` 这样的字段，在 `fscanf` 读入后调用 `trim` 可以去除多余的换行符残留。

```c
// utils.h
```

## 5. 输入验证函数

### 5.1 手机号验证

```c
// utils.h
bool isValidPhone(const char* phone);
```

**验证规则**：中国手机号共 11 位，全部为数字。

**实现思路**：
1. **第1步**：如果 `phone == NULL`，返回 `false`
2. **第2步**：检查 `strlen(phone) == 11`，不是则返回 `false`
3. **第3步**：`for` 循环遍历 11 位，逐个检查 `isdigit()`
4. **第4步**：全部通过返回 `true`，否则返回 `false`

---

### 5.2 身份证号验证

```c
// utils.h
bool isValidIdCard(const char* idCard);
```

**验证规则**：中国身份证号共 18 位，前 17 位为数字，第 18 位为数字或 X/x。

**实现思路**：
1. **第1步**：如果 `idCard == NULL`，返回 `false`
2. **第2步**：检查 `strlen(idCard) == 18`，不是则返回 `false`
3. **第3步**：前 17 位用 `isdigit()` 逐个检查
4. **第4步**：第 18 位检查 `isdigit() || idCard[17]=='X' || idCard[17]=='x'`
5. **第5步**：全部通过返回 `true`，否则返回 `false`

---

### 5.3 日期有效性验证

```c
// utils.h
bool isValidDate(int year, int month, int day);
```

**实现思路**：
1. **第1步**：检查 `1900 <= year <= 2100`
2. **第2步**：检查 `1 <= month <= 12`
3. **第3步**：检查 `1 <= day <= 31`（精确月份天数验证可后续扩展）
4. **第4步**：全部通过返回 `true`，否则返回 `false`

**⚠️ 注意**：团队版本直接接收 `int year, int month, int day` 三个参数，不再是 `char* date` 字符串。

## 6. 提示与暂停

```c
// utils.h
void pause(const char* message);
```

**实现思路**：
1. **第1步**：`printf("%s", message)` 打印提示文字（不含换行）
2. **第2步**：`getchar()` 等待用户按任意键继续（吞掉换行符）
