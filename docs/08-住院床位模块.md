# 住院与床位模块 - 教程文档

> 本文档详细介绍住院记录管理和床位管理模块

---

## 1. 模块概述

### 1.1 功能描述

**住院管理**：
- 入院登记（自动分配床位）
- 出院结算（计算费用、释放床位）
- 住院状态跟踪

**床位管理**：
- 床位增删改查
- 病区管理
- 床位状态跟踪

### 1.2 核心亮点

**自动床位分配**：
- 入院时自动分配空闲床位
- 出院时自动释放床位
- 减少人工操作

## 2. 住院数据结构

```c
// hospitalization.h
typedef struct Hospitalization {
    char recordNo[20];           // 住院单号（如HOS001）
    char patientCardNo[20];      // 病人卡号
    char patientName[50];       // 病人姓名
    char bedNo[20];             // 床位号
    double prepay;              // 预交金额
    double totalCost;           // 总费用
    char admissionDate[20];     // 入院日期
    char status[20];            // 状态（在院/已出院）
    
    struct Hospitalization* next;
    struct Hospitalization* pre;
} Hospitalization;
```

## 3. 床位数据结构

```c
// bed.h
typedef struct Bed {
    char ward[30];               // 病区
    char bedNo[20];             // 床位号
    char patientCardNo[20];    // 病人卡号（空=无病人）
    char patientName[50];      // 病人姓名
    char status[20];           // 状态（空闲/占用/维修）
    
    struct Bed* next;
    struct Bed* pre;
} Bed;
```

## 4. 核心函数

### 4.1 自动分配床位

```c
char* allocateBed(Bed* head, char* patientCardNo, char* patientName) {
    Bed* p = head;
    
    // 遍历找空闲床位
    while (p != NULL) {
        if (strcmp(p->status, "空闲") == 0) {
            // 分配床位
            strcpy(p->patientCardNo, patientCardNo);
            strcpy(p->patientName, patientName);
            strcpy(p->status, "占用");
            
            printf("[INFO] 分配床位成功：%s - %s\n", p->ward, p->bedNo);
            return p->bedNo;
        }
        p = p->next;
    }
    
    printf("[ERROR] 暂无空闲床位！\n");
    return NULL;
}
```

### 4.2 释放床位

```c
void freeBed(Bed* b) {
    if (b == NULL) return;
    
    strcpy(b->patientCardNo, "空");
    strcpy(b->patientName, "空");
    strcpy(b->status, "空闲");
    
    printf("[INFO] 释放床位成功：%s - %s\n", b->ward, b->bedNo);
}
```

### 4.3 入院登记

```c
void addHospitalization(Hospitalization** head, Hospitalization** tail,
                        char* patientCardNo, char* patientName,
                        char* bedNo, double prepay) {
    
    Hospitalization* now = (Hospitalization*)malloc(sizeof(Hospitalization));
    now->next = now->pre = NULL;
    
    sprintf(now->recordNo, "HOS%s", generateUniqueId());
    safeStringCopy(now->patientCardNo, patientCardNo, 20);
    safeStringCopy(now->patientName, patientName, 50);
    safeStringCopy(now->bedNo, bedNo, 20);
    now->prepay = prepay;
    now->totalCost = 0;
    getCurrentTime(now->admissionDate, 20);
    strcpy(now->status, "在院");
    
    if (*head == NULL) {
        *head = *tail = now;
    } else {
        (*tail)->next = now;
        now->pre = *tail;
        *tail = now;
    }
}
```

### 4.4 出院结算

```c
double dischargePatient(Hospitalization* h, double totalCost) {
    if (h == NULL) return 0;
    
    h->totalCost = totalCost;
    strcpy(h->status, "已出院");
    
    double refund = h->prepay - totalCost;
    
    printf("\n========== 出院结算单 ==========\n");
    printf("住院单号：%s\n", h->recordNo);
    printf("病人姓名：%s\n", h->patientName);
    printf("住院日期：%s\n", h->admissionDate);
    printf("总费用：%.2f元\n", totalCost);
    printf("预交金额：%.2f元\n", h->prepay);
    printf("应退金额：%.2f元\n", refund);
    printf("================================\n");
    
    return refund;
}
```
