# 医生模块 - 教程文档

> 本文档详细介绍医生信息管理模块的实现

---

## 1. 模块概述

### 1.1 功能描述

医生模块负责管理医生的基本信息，包括：
- 添加新医生（自动生成工号）
- 删除医生
- 修改出诊信息
- 查询医生
- 医生接诊数量限制

### 1.2 数据存储

- **数据文件**：`data/doctor.txt`
- **唯一标识**：工号（格式：DOC + 序号）

---

## 2. 数据结构

```c
// doctor.h
typedef struct Doctor {
    char empNo[20];              // 工号（如DOC001）
    char name[50];               // 姓名
    char dept[50];               // 科室
    char schedule[100];          // 出诊时间
    int maxPatients;             // 每日最大接诊数
    int currentPatients;         // 今日已接诊数
    
    struct Doctor* next;
    struct Doctor* pre;
} Doctor;
```

---

## 3. 核心函数

### 3.1 添加医生

```c
void addDoctor(Doctor** head, Doctor** tail, 
               char name[], char dept[], char schedule[], int maxPatients) {
    
    Doctor* now = (Doctor*)malloc(sizeof(Doctor));
    now->next = now->pre = NULL;
    
    // 生成唯一工号
    sprintf(now->empNo, "DOC%s", generateUniqueId());
    
    safeStringCopy(now->name, name, 50);
    safeStringCopy(now->dept, dept, 50);
    safeStringCopy(now->schedule, schedule, 100);
    now->maxPatients = maxPatients;
    now->currentPatients = 0;
    
    // 插入链表
    if (*head == NULL) {
        *head = *tail = now;
    } else {
        (*tail)->next = now;
        now->pre = *tail;
        *tail = now;
    }
    
    printf("[INFO] 添加医生成功！工号：%s\n", now->empNo);
}
```

### 3.2 医生接诊检查

```c
int canAcceptPatient(Doctor* d) {
    if (d == NULL) return 0;
    return d->currentPatients < d->maxPatients;
}

void incrementPatientCount(Doctor* d) {
    if (d != NULL && d->currentPatients < d->maxPatients) {
        d->currentPatients++;
    }
}
```

### 3.3 重置每日接诊数

```c
void resetDailyPatients(Doctor* head) {
    Doctor* p = head;
    while (p != NULL) {
        p->currentPatients = 0;
        p = p->next;
    }
}
```

## 4. 科室统计

```c
void getDeptStats(Doctor* head, char* dept, int* count) {
    *count = 0;
    Doctor* p = head;
    while (p != NULL) {
        if (strcmp(p->dept, dept) == 0) {
            (*count)++;
        }
        p = p->next;
    }
}
```
