## 1. 链表基础概念

### 1.1 什么是链表？

链表是一种线性数据结构，由一系列节点组成，每个节点包含数据和指向下一个节点的指针。

```
┌──────┬────┐    ┌──────┬────┐    ┌──────┬────┐
│ 数据1 │next│ → │ 数据2 │next│ → │ 数据3 │next│ → NULL
└──────┴────┘    └──────┴────┘    └──────┴────┘
```

### 1.2 为什么用链表？

| 特性 | 数组 | 链表 |
|------|------|------|
| 大小 | 固定 | 可动态变化 |
| 插入 | 需要移动元素 | 只需修改指针 |
| 删除 | 需要移动元素 | 只需修改指针 |
| 访问 | O(1)随机访问 | O(n)遍历 |
| 内存 | 连续 | 不连续 |

**本项目选择链表的原因**：
- 数据量不确定（病人数量会变化）
- 插入删除操作频繁
- 实现相对简单

## 2. 单向链表 vs 双向链表

### 2.1 单向链表

每个节点只包含指向下一个节点的指针：

```c
struct Node {
    DataType data;
    struct Node* next;  // 只能向后遍历
};
```

```
head → [A|next] → [B|next] → [C|next] → NULL
```

### 2.2 双向链表

每个节点包含指向前后两个节点的指针：

```c
struct Node {
    struct Node* pre;   // 指向前一个节点
    DataType data;
    struct Node* next;   // 指向后一个节点
};
```

```
NULL ← [pre|A|next] ⇄ [pre|B|next] ⇄ [pre|C|next] → NULL
       ↑__________________________________|
```

**双向链表的优势**：
- 可以双向遍历
- 删除节点更方便（不需要知道前一个节点）
- 本项目采用双向链表

## 4. 链表操作详解

### 4.1 初始化链表

```c
void initPatientChain(Patient** head, Patient** tail) {
    *head = *tail = NULL;  // 初始化为空链表
}
```

### 4.2 添加节点（尾插法）

```c
void addPatient(Patient** head, Patient** tail, char name[]) {
    // 1. 分配内存
    Patient* now = (Patient*)malloc(sizeof(Patient));
    
    // 2. 填充数据
    strcpy(now->name, name);
    now->next = now->pre = NULL;
    
    // 3. 插入链表
    if (*head == NULL) {
        // 链表为空，新节点既是头又是尾
        *head = *tail = now;
    } else {
        // 链表不为空，插入尾部
        (*tail)->next = now;
        now->pre = *tail;
        *tail = now;
    }
}
```

**尾插法示意图**：

```
初始状态：
head → NULL, tail → NULL

插入第一个节点A：
head → [A|null|null] ← tail

插入第二个节点B：
head → [A|next|B] → [B|null|A] ← tail

插入第三个节点C：
head → [A|next|B] ⇄ [B|next|C] ⇄ [C|null|B] ← tail
```

### 4.3 查找节点

```c
Patient* findPatientByName(Patient* head, char name[]) {
    Patient* p = head;
    
    while (p != NULL) {
        if (strcmp(p->name, name) == 0) {
            return p;  // 找到
        }
        p = p->next;
    }
    
    return NULL;  // 未找到
}
```

### 4.4 删除节点

```c
void delPatient(Patient** head, Patient** tail, Patient* p) {
    if (p == NULL) return;
    
    // 情况1：只有一个节点
    if (p == *head && p == *tail) {
        *head = *tail = NULL;
    }
    // 情况2：删除头节点
    else if (p == *head) {
        *head = (*head)->next;
        (*head)->pre = NULL;
    }
    // 情况3：删除尾节点
    else if (p == *tail) {
        *tail = (*tail)->pre;
        (*tail)->next = NULL;
    }
    // 情况4：删除中间节点
    else {
        p->pre->next = p->next;
        p->next->pre = p->pre;
    }
    
    free(p);  // 释放内存
}
```

**删除操作示意图**：

```
删除中间节点B：
         ┌──────────────────────────┐
         ↓                          ↑
head → [A|next|B] ⇄ [B|next|C] ⇄ [C|next|D] → NULL
              ↓_______________↑
                    ↓
                   [B]  ← 被删除
                    ↓
              free(B)

结果：
head → [A|next|B] ⇄ [C|next|D] → NULL
```

### 4.5 遍历链表

```c
void listAllPatients(Patient* head) {
    Patient* p = head;
    
    while (p != NULL) {
        printf("卡号: %s, 姓名: %s\n", p->cardNo, p->name);
        p = p->next;
    }
}
```

### 4.6 释放链表内存

```c
void freePatientChain(Patient* head) {
    Patient* p = head;
    
    while (p != NULL) {
        Patient* next = p->next;
        free(p);
        p = next;
    }
}
```

## 6. 常见问题

**Q1: 链表和数组哪个好？**
- 数据量固定且需要随机访问 → 数组
- 数据量变化大，需要频繁插入删除 → 链表

**Q2: 为什么要保存head和tail两个指针？**
- head：遍历整个链表
- tail：O(1)时间在尾部添加

**Q3: 什么是野指针？**
- 未初始化的指针或已释放但未置NULL的指针
- 使用野指针会导致程序崩溃
- 养成习惯：malloc后立即初始化，free后立即置NULL
