# 项目介绍 - 教程文档

> 本文档详细介绍了医院综合信息管理系统的项目背景、功能模块和技术架构

## 1. 项目概述

### 1.1 项目名称
**医院综合信息管理系统**（Hospital Management System）

### 1.2 项目背景
本项目是吉林大学软件工程专业《程序设计基础课程设计》的结课项目，旨在实现一个小型医院的综合信息管理系统。

### 1.3 开发目标
- 掌握C语言/C++基本编程技能
- 理解链表数据结构
- 学会文件IO操作
- 了解GUI图形界面开发
- 体验团队协作开发流程

## 2. 功能模块概览

### 2.1 六大核心模块

| 模块 | 功能 | 数据文件 |
|------|------|----------|
| 病人信息管理 | 门诊卡号、姓名、性别、身份证、电话 | patient.txt |
| 医生信息管理 | 工号、姓名、科室、出诊时间、接诊上限 | doctor.txt |
| 挂号记录管理 | 挂号单号、病人、医生、科室、日期、状态 | registration.txt |
| 药品信息管理 | 编号、通用名、商品名、规格、单价、库存 | medicine.txt |
| 住院记录管理 | 住院单号、床位、预交金额、出院结算 | hospitalization.txt |
| 床位信息管理 | 病区、床位号、状态（空闲/占用/维修） | bed.txt |

### 2.2 附加功能

| 功能 | 说明 |
|------|------|
| 登录系统 | 用户/管理员登录，密码MD5加密 |
| 购药记录 | 记录病人购药信息 |
| 统计报表 | 业务量、收入等数据统计 |
| 数据持久化 | 启动加载、退出保存 |

## 3. 技术架构

### 3.1 技术栈

```
┌─────────────────────────────────────────┐
│           GUI 图形界面层                 │
│         (StellarX / EasyX)              │
├─────────────────────────────────────────┤
│           业务逻辑层                     │
│  (patient / doctor / medicine / ...)    │
├─────────────────────────────────────────┤
│           数据结构层                     │
│            (双向链表)                    │
├─────────────────────────────────────────┤
│           文件IO层                      │
│          (txt 文件存储)                  │
└─────────────────────────────────────────┘
```

### 3.2 数据结构

**核心数据结构**：双向链表

```c
typedef struct Node {
    DataType data;        // 数据
    struct Node* next;    // 下一个节点
    struct Node* pre;     // 上一个节点
} Node;
```

### 3.3 文件存储

每种数据对应一个txt文件，格式为：
```
1          ← 记录有效标志
数据1
数据2
数据3
...

-1         ← 文件结束标志
```

## 4. 项目亮点

### 4.1 GUI图形界面
- 使用StellarX框架（基于EasyX）
- 现代化界面设计
- TabControl左侧导航栏
- Table表格组件显示数据

### 4.2 库存预警机制
- 药品设置最低库存值
- 低于阈值自动提示
- 方便药房管理

### 4.3 床位自动分配
- 入院时自动分配空闲床位
- 出院时自动释放床位
- 减少人工操作

### 4.4 完整的统计报表
- 医生业务量统计
- 科室统计
- 住院统计
- 收入统计
- 全院数据汇总

## 6. 常见问题

**Q1: 为什么选择链表而不是数组？**
- 链表大小可动态变化
- 插入删除效率高
- 适合数据量不确定的场景

**Q2: 为什么用文本文件而不是数据库？**
- 简单易用，无需额外安装
- 适合小型项目
- 便于调试和查看数据

**Q3: 为什么用CMake而不是直接用IDE？**
- 跨平台支持
- 项目结构清晰
- 易于团队协作
