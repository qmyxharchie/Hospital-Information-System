## 1. 模块概述

### 1.1 为什么用文本文件？

- 简单易用，无需数据库
- 便于调试和查看数据
- 适合小型项目
- 无需额外安装软件

### 1.2 数据目录定义

在 `file_io.h` 中用宏定义文件路径：

```c
// file_io.h
#define DATA_DIR "data/"
#define BACKUP_DIR "backup/"

#define PATIENT_FILE    DATA_DIR "patient.txt"
#define DOCTOR_FILE     DATA_DIR "doctor.txt"
#define MEDICINE_FILE   DATA_DIR "medicine.txt"
#define PURCHASE_FILE   DATA_DIR "purchase.txt"
#define HOSPITAL_FILE   DATA_DIR "hospitalization.txt"
#define BED_FILE        DATA_DIR "bed.txt"
#define REGISTRATION_FILE DATA_DIR "registration.txt"
#define USER_FILE       DATA_DIR "user.txt"
```

## 2. 文件格式设计

每个数据文件的通用格式：

- `1` + 各字段值 → 一条有效记录
- `-1` → 文件结束标记
- 每条记录之间留空行

## 3. 读取文件（从文件加载到链表）

> **统一格式**：`[返回类型] 函数名(...)` — 所属头文件

```c
// file_io.h
void buildPatientChain(Patient** head, Patient** tail);          // 加载病人列表
void buildDoctorChain(Doctor** head, Doctor** tail);              // 加载医生列表
void buildMedicineChain(MedicineNode** head, MedicineNode** tail);  // 加载药品列表
void buildPurchaseChain(PurchaseNode** head, PurchaseNode** tail);   // 加载购药记录
void buildHospitalizationChain(HospitalizationNode** head, HospitalizationNode** tail);  // 加载住院记录
void buildBedChain(BedNode** head, BedNode** tail);            // 加载床位列表
void buildRegistrationChain(Registration** head, Registration** tail);  // 加载挂号记录
void buildUserChain(User** head, User** tail);                 // 加载用户列表
```

**实现思路（以病人为例）**：
1. **第1步**：`fopen(PATIENT_FILE, "r")` 打开文件
2. **第2步**：如果文件不存在（fp==NULL），用 `fopen(PATIENT_FILE, "w")` 创建空文件，写入"-1"，关闭并返回
3. **第3步**：定义 `Patient* pre = NULL` 跟踪上一个节点
4. **第4步**：`while(1)` 循环：
   - `fscanf(fp, "%d", &opt)` 读入标记
   - `opt == -1` → `break` 跳出循环
   - `opt == 1` → `malloc(sizeof(Patient))` 分配节点，初始化 `node->next = node->pre = NULL`
   - `fscanf(fp, "%s", node->data.cardNo)` 依次读入各字段（注意：用 `data.xxx` 访问字段）
   - 尾插法：第一个节点使 `*head = now`，后续节点 `pre->next = now; now->pre = pre`
   - `pre = now` 更新 pre
5. **第5步**：循环结束后，`*tail = pre`
6. **第6步**：`fclose(fp)` 关闭文件

## 4. 写入文件（从链表保存到文件）

```c
// file_io.h
// [修正备注-20260412] 原 rebuildPatientFile(Patient head)、rebuildDoctorFile(Doctor head)、
// rebuildUserFile(User head) 三处均为值传递（Pass-by-Value），声明与实现矛盾：
// 实现思路中写的是 "Patient* p = head"，即假设 head 本身是指针。
// 值传递导致函数内无法通过 ->next 遍历链表，属于严重错误，已统一修正为指针传递：
void rebuildPatientFile(Patient* head);         // 保存病人列表
void rebuildDoctorFile(Doctor* head);            // 保存医生列表
void rebuildMedicineFile(MedicineNode* head);   // 保存药品列表
void rebuildPurchaseFile(PurchaseNode* head);   // 保存购药记录
void rebuildHospitalizationFile(HospitalizationNode* head);  // 保存住院记录
void rebuildBedFile(BedNode* head);            // 保存床位列表
void rebuildRegistrationFile(Registration* head);  // 保存挂号记录
void rebuildUserFile(User* head);              // 保存用户列表
```

**实现思路（以病人为例）**：
1. **第1步**：`fopen(PATIENT_FILE, "w")` 以写入模式打开（会清空原文件）
2. **第2步**：`Patient* p = head`
3. **第3步**：`while(p != NULL)` 循环：
   - `fprintf(fp, "1\n")` 写有效标记
   - `fprintf(fp, "%s\n", p->data.cardNo)` 依次写入所有字段（注意：用 `data.xxx`）
   - `fprintf(fp, "\n")` 每条记录后写空行
   - `p = p->next`
4. **第4步**：循环结束后 `fprintf(fp, "-1\n")` 写结束标记
5. **第5步**：`fclose(fp)` 关闭文件

## 5. 数据备份

```c
// file_io.h
int backupAllData();    // 备份所有数据文件
int copyFile(char* source, char* dest);  // 复制单个文件
```

**backupAllData 实现思路**：
1. **第1步**：调用 `getCurrentTime` 获取当前日期，用于生成带时间戳的备份文件名
2. **第2步**：拼接备份路径，如 `backup/patient_20260407.txt`
3. **第3步**：对所有数据文件循环调用 `copyFile`
4. **第4步**：打印备份结果

**copyFile 实现思路**：
1. **第1步**：`fopen(source, "rb")` 以二进制读模式打开源文件
2. **第2步**：`fopen(dest, "wb")` 以二进制写模式打开目标文件
3. **第3步**：`while(fread(buffer, 1, size, src) > 0)` 循环读取并写入，直到 EOF
4. **第4步**：关闭两个文件，返回 1

---

## 6. 注意事项

1. **每次修改数据后都要调用对应的 rebuildXxxFile**，否则退出程序后数据会丢失
2. 程序启动时应调用所有 `buildXxxChain`，加载上次保存的数据
3. 备份文件放在 `backup/` 目录，不要和 `data/` 混在一起
4. **⚠️ rebuildPatientFile 和 rebuildDoctorFile 的团队头文件参数是值传递**（`Patient head` / `Doctor head`），即传入头节点本身，不需要传入指针
