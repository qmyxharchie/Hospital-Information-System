## 1. 项目介绍

### 1.1 项目背景

本项目是一个小型医院角色综合信息管理系统，实现了医院日常运营中常见的信息管理功能。

### 1.2 功能模块

| 模块 | 功能描述 | 核心操作 |
|------|----------|----------|
| 病人管理 | 管理病人基本信息 | 增删改查 |
| 医生管理 | 管理医生排班信息 | 增删改查 |
| 挂号管理 | 记录病人挂号信息 | 挂号、取消、完成 |
| 药品管理 | 管理药品库存 | 增删改查、库存预警 |
| 住院管理 | 管理住院病人 | 入院、出院结算 |
| 床位管理 | 管理床位状态 | 分配、释放 |
| 统计报表 | 数据统计汇总 | 各类统计查询 |

### 1.3 技术栈

- **语言**：C/C++
- **图形界面**：StellarX（基于EasyX）
- **构建工具**：CMake
- **数据结构**：双向链表
- **编译器**：Visual Studio / MinGW

## 4. 代码详解

### 4.1 数据结构：双向链表

本项目使用双向链表存储所有数据。以下是病人结构体的示例：

```c
// patient.h
typedef struct Patient {
    char cardNo[20];          // 门诊卡号（唯一标识）
    char name[50];            // 姓名
    char gender[10];          // 性别
    char idCard[20];          // 身份证号
    char phone[15];           // 联系电话
    int isActive;             // 是否住院（0=否，1=是）
    
    struct Patient* next;     // 下一个节点
    struct Patient* pre;       // 上一个节点
} Patient;
```

**链表操作示意图**：

```
┌─────────┐    ┌─────────┐    ┌─────────┐
│ Patient1 │ ←→ │ Patient2 │ ←→ │ Patient3 │
└─────────┘    └─────────┘    └─────────┘
   HEAD          next          next       TAIL
     ↑                                        ↑
     └────────────── pre ──────────────────────┘
```

### 4.2 核心函数解析

#### 4.2.1 添加病人

```c
void addPatient(Patient** head, Patient** tail, 
                char name[], char gender[], char idCard[], char phone[]) {
    // 1. 分配内存
    Patient* now = (Patient*)malloc(sizeof(Patient));
    now->next = now->pre = NULL;
    
    // 2. 填充数据
    safeStringCopy(now->name, name, 50);
    safeStringCopy(now->gender, gender, 10);
    safeStringCopy(now->idCard, idCard, 20);
    safeStringCopy(now->phone, phone, 15);
    now->isActive = 0;
    
    // 3. 生成唯一卡号
    sprintf(now->cardNo, "PT%s", generateUniqueId());
    
    // 4. 插入链表尾部
    if (*head == NULL) {
        *head = *tail = now;
    } else {
        (*tail)->next = now;
        now->pre = *tail;
        *tail = now;
    }
    
    printf("[INFO] 添加病人成功！卡号：%s\n", now->cardNo);
}
```

#### 4.2.2 查找病人

```c
Patient* findPatientByCardNo(Patient* head, char cardNo[]) {
    Patient* p = head;
    while (p != NULL) {
        if (strcmp(p->cardNo, cardNo) == 0) {
            return p;  // 找到返回指针
        }
        p = p->next;
    }
    return NULL;  // 未找到返回NULL
}
```

#### 4.2.3 删除病人

```c
void delPatient(Patient** head, Patient** tail, Patient* p) {
    if (p == NULL) return;
    
    // 特殊情况：只有一个节点
    if (p == *head && p == *tail) {
        *head = *tail = NULL;
    }
    // 删除头节点
    else if (p == *head) {
        *head = (*head)->next;
        (*head)->pre = NULL;
    }
    // 删除尾节点
    else if (p == *tail) {
        *tail = (*tail)->pre;
        (*tail)->next = NULL;
    }
    // 删除中间节点
    else {
        p->pre->next = p->next;
        p->next->pre = p->pre;
    }
    
    free(p);  // 释放内存
}
```

## 7. 常见问题

### Q1: CMake配置失败？

**问题**：运行cmake时报错 "CMAKE_CXX_COMPILER not set"

**解决**：
1. 确保已安装C++编译器
2. 安装Visual Studio时选择"使用C++的桌面开发"
3. 或安装MinGW：`pacman -S mingw-w64-x86_64-gcc`

### Q2: 找不到easyx.h？

**问题**：编译时报错 "easyx.h: No such file or directory"

**解决**：
1. 下载并安装EasyX：https://easyx.cn/
2. 选择对应的Visual Studio版本
3. 重新运行cmake

### Q3: 中文路径导致编译失败？

**问题**：路径中的中文字符导致编译错误

**解决**：
1. 将项目移到英文路径，如 `D:\hospital-management`
2. 不要在包含中文的文件夹中编译

### Q4: 程序运行时黑屏/崩溃？

**问题**：程序运行后界面异常或崩溃

**解决**：
1. 确保EasyX已正确安装
2. 确保image文件夹和图片存在
3. 检查data文件夹是否可写

### Q5: 数据无法保存？

**问题**：退出程序后数据丢失

**解决**：
1. 确保data文件夹存在
2. 确保程序有写入权限
3. 检查data文件中数据格式是否正确

### Q6: 编译太慢？

**问题**：编译时间过长

**解决**：
1. 使用Release模式编译：`cmake --build . --config Release`
2. 只编译修改过的文件
3. 考虑使用预编译头文件

## 8. 答辩准备

### 8.1 代码理解要点

**必须能回答的问题**：

1. **为什么用链表而不是数组？**
   - 链表大小可变，数组需要预先固定大小
   - 链表插入删除方便，数组需要移动大量元素
   - 适合数据量不确定的场景

2. **什么是双向链表？**
   - 每个节点包含前驱和后继指针
   - 可以从头到尾也可以从尾到头遍历
   - 删除操作更方便

3. **文件存储格式为什么这样设计？**
   - 每条记录前用1表示有效，-1表示结束
   - 便于程序判断记录边界
   - 支持增量添加数据

4. **什么是MD5加密？**
   - 密码哈希算法
   - 相同密码产生相同哈希值
   - 不可逆向解密，保护用户密码

5. **项目的亮点是什么？**
   - GUI图形界面
   - 完整的CRUD功能
   - 库存预警机制
   - 统计报表功能
