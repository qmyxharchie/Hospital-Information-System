## 1. 模块概述

### 1.1 功能描述

病人模块负责管理病人的基本信息：
- 添加新病人（自动生成门诊卡号）
- 删除病人
- 修改病人信息
- 查询病人
- 列表显示所有病人

### 1.2 数据存储

- **数据文件**：`data/patient.txt`
- **唯一标识**：门诊卡号（格式：`PT` + 时间戳）

---

## 2. 数据结构

在 `patient.h` 中定义 Patient 结构体（Data + Node 分离模式）：

**PatientData**：纯数据，无链表指针
```c
// patient.h
typedef struct PatientData {
    char cardNo[20];     // 门诊卡号（唯一标识，如"PT20260411"）
    char name[50];      // 姓名
    char gender[10];    // 性别（男/女）
    char idCard[20];    // 身份证号（唯一）
    char phone[15];     // 联系电话
    int isActive;       // 住院状态：0=未住院, 1=住院中
} PatientData;
```

**Patient**：链表节点，包裹 PatientData + 前后指针
```c
// patient.h
typedef struct Patient {
    PatientData data;            // 病人数据
    struct Patient* next;        // 指向下一个节点
    struct Patient* pre;         // 指向前一个节点（双向链表）
} Patient;
```

## 3. 函数详解

> **统一格式**：`[返回类型] 函数名(...)` — 所属头文件

### 3.1 从文件加载数据

```c
// patient.h
void buildPatientChain(Patient* head, Patient* tail);
```

**实现思路**：
1. **第1步**：`fopen(PATIENT_FILE, "r")` 打开文件
2. **第2步**：如果文件不存在（fp==NULL），用 `fopen(PATIENT_FILE, "w")` 创建空文件，写入"-1"，关闭并返回
3. **第3步**：定义 `Patient* pre = NULL` 跟踪上一个节点
4. **第4步**：`while(1)` 循环读入：
   - `fscanf(fp, "%d", &opt)` 读入标记
   - `opt == -1` → `break` 跳出循环
   - `opt == 1` → 分配节点：`malloc(sizeof(Patient))`
   - 初始化 `node->next = node->pre = NULL`
   - `fscanf(fp, "%s", node->data.cardNo)` 依次读入各字段
   - 尾插法插入：第一个节点使 `*head = now`，后续节点 `pre->next = now; now->pre = pre`
   - `pre = now` 更新 pre
5. **第5步**：循环结束后，`*tail = pre`
6. **第6步**：`fclose(fp)` 关闭文件

### 3.2 添加病人

```c
// patient.h
void addPatient(Patient** head, Patient** tail,
    char name[], char gender[], char idCard[], char phone[]);
```

**实现思路**：
1. **第1步**：`malloc(sizeof(Patient))` 分配 Patient 节点
2. **第2步**：调用 `generateUniqueId("PT", id)` 生成唯一卡号，`strcpy(node->data.cardNo, "PT"); strcat(node->data.cardNo, id)`
3. **第3步**：`strcpy(node->data.name, name)` 等填充各字段
4. **第4步**：`node->data.isActive = 0`（初始不住院）
5. **第5步**：尾插法插入链表（参考数据结构章节）
6. **第6步**：调用 `rebuildPatientFile(*head)` 保存到文件
7. **第7步**：打印添加成功信息（含卡号）

---

### 3.3 删除病人

```c
// patient.h
void delPatient(Patient* head, Patient* tail, PatientData p);
```

**实现思路**：
1. **第1步**：边界检查（head==NULL 直接返回）
2. **第2步**：遍历链表，找到 `PatientData` 内容与 `p` 匹配的节点
3. **第3步**：分四种情况处理（唯一节点 / 头节点 / 尾节点 / 中间节点），参考数据结构章节的删除逻辑
4. **第4步**：更新前后节点的 next / pre 指针
5. **第5步**：`free(pNode)` 释放内存
6. **第6步**：调用 `rebuildPatientFile(head)` 保存文件

### 3.4 修改病人信息

```c
// patient.h（可自行扩展）
void modifyPatient(Patient* p, char phone[]);
```

**实现思路**：

2. **第2步**：调用 `safeStringCopy(p->data.phone, phone, 15)` 安全复制电话号码
3. **第3步**：调用 `rebuildPatientFile(...)` 保存文件

### 3.5 查询病人

```c
// patient.h
Patient* findPatientByCardNo(Patient* head, char* cardNo);   // 按卡号精确查找
Patient* findPatientByName(Patient* head, char* name);        // 按姓名模糊/精确查找
```

**实现思路**：
1. **第1步**：`Patient* cur = head` 从头节点开始
2. **第2步**：`while(cur != NULL)` 遍历链表
3. **第3步**：`strcmp(cur->data.cardNo, cardNo) == 0` 比对卡号，或 `strcmp(cur->data.name, name) == 0` 比对姓名
4. **第4步**：找到则返回 `cur`，遍历完没找到返回 `NULL`

---

### 3.6 列表显示

```c
// patient.h
void listAllPatients(Patient* head);
```

**实现思路**：
1. **第1步**：`Patient* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历
3. **第3步**：依次 `printf` 打印各字段（卡号、姓名、性别、身份证、电话、住院状态）
4. **第4步**：`cur = cur->next`

---

### 3.7 保存到文件

```c
// patient.h
void rebuildPatientFile(Patient* head);
```

**实现思路**：
1. **第1步**：`fopen(PATIENT_FILE, "w")` 以写入模式打开（清空原文件）
2. **第2步**：`Patient* p = head`
3. **第3步**：`while(p != NULL)` 循环：
   - `fprintf(fp, "1\n")` 写有效标记
   - `fprintf(fp, "%s\n", p->data.cardNo)` 依次写入各字段
   - `fprintf(fp, "\n")` 每条记录后写空行
   - `p = p->next`
4. **第4步**：循环结束后 `fprintf(fp, "-1\n")` 写结束标记
5. **第5步**：`fclose(fp)` 关闭文件
