## 1. 模块概述

### 1.1 功能描述

药品模块负责管理药品的库存信息：
- 添加新药品
- 删除药品
- 修改药品信息
- 补充库存
- 库存预警检查
- 购药（扣减库存）
- 购药记录管理

### 1.2 核心亮点

**库存预警机制**：每个药品设置最低库存值，当库存 ≤ 最低值时自动提示，方便药房管理。

## 3. 核心函数

> **统一格式**：`[返回类型] 函数名(...)` — 所属头文件

---

### 3.1 库存预警检查

```c
// medicine.h
void checkLowStock(MedicineNode* head);
```

**实现思路**：
1. **第1步**：`MedicineNode* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历整个链表
3. **第3步**：检查 `cur->data.stock <= cur->data.minStock`
4. **第4步**：低于阈值则打印预警信息（药品名、当前库存、最低库存）
5. **第5步**：`cur = cur->next`
6. **第6步**：遍历结束，统计并显示预警药品数量

---

### 3.2 购药（扣减库存）

```c
// medicine.h
void purchaseMedicine(MedicineNode* head, char* medNo, int quantity);
```

**实现思路**：
1. **第1步**：调用 `findMedicineByNo(head, medNo)` 查找药品
2. **第2步**：如果药品不存在，打印错误信息，返回
3. **第3步**：如果 `stock < quantity`，打印"库存不足"，返回
4. **第4步**：`stock -= quantity` 扣减库存
5. **第5步**：打印购药成功和当前库存
6. **第6步**：如果扣减后 `stock <= minStock`，再次调用 `checkLowStock` 提示预警
7. **第7步**：调用 `rebuildMedicineFile(head)` 保存

---

### 3.3 补充库存

```c
// medicine.h
void replenishStock(MedicineNode* head, char* medNo, int quantity);
```

**实现思路**：
1. **第1步**：调用 `findMedicineByNo(head, medNo)` 查找药品
2. **第2步**：如果不存在，打印错误，返回
3. **第3步**：`stock += quantity` 增加库存
4. **第4步**：打印补货成功信息
5. **第5步**：调用 `rebuildMedicineFile(head)` 保存

---

### 3.4 购药记录创建

```c
// medicine.h
void addPurchaseRecord(PurchaseNode** head, PurchaseNode** tail, ...);
```

**实现思路**：
1. **第1步**：`malloc(sizeof(PurchaseNode))` 分配节点
2. **第2步**：调用 `generateUniqueId("PUR", id)` 生成购药单号
3. **第3步**：填充所有字段（购药单号、病人卡号、药品编号、数量、总费用、日期）
4. **第4步**：尾插法插入链表
5. **第5步**：同时调用 `purchaseMedicine` 扣减对应药品库存
6. **第6步**：调用 `rebuildPurchaseFile(*head)` 保存购药记录

---

### 3.5 查询函数

```c
// medicine.h
MedicineNode* findMedicineByNo(MedicineNode* head, char* medNo);       // 按药品编号查找
MedicineNode* findMedicineByName(MedicineNode* head, char* name);     // 按药品名查找
```

**实现思路**：
1. **第1步**：`MedicineNode* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历链表
3. **第3步**：`strcmp(cur->data.medNo, medNo) == 0` 等条件比对
4. **第4步**：找到则返回 `cur`，否则返回 `NULL`
