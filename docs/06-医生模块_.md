# 医生模块 - 学习版

> 本文档为学习版，代码部分已替换为函数名和实现思路提示。
> 结构体采用 Data + Node 分离模式（见 patient.h），每个函数标注返回类型和头文件来源。

---

## 1. 模块概述

### 1.1 功能描述

医生模块负责管理医生的基本信息：
- 添加新医生（自动生成工号）
- 删除医生
- 修改出诊信息
- 查询医生
- 医生接诊数量限制

### 1.2 数据存储

- **数据文件**：`data/doctor.txt`
- **唯一标识**：工号（格式：`DOC` + 时间戳）

---

## 2. 数据结构

在 `doctor.h` 中定义 Doctor 结构体（Data + Node 分离模式）：

**DoctorData**：纯数据
```c
// doctor.h
typedef struct DoctorData {
    char empNo[20];          // 工号（唯一标识，如"DOC001"）
    char name[50];         // 姓名
    char dept[50];         // 科室（如"内科"、"外科"）
    char schedule[100];    // 出诊时间（如"周一、周三、周五"）
    int maxPatients;       // 每日最大接诊数
    int currentPatients;   // 当日已挂号数
} DoctorData;
```

**Doctor**：链表节点
```c
// doctor.h
typedef struct Doctor {
    DoctorData data;
    struct Doctor* next;
    struct Doctor* pre;
} Doctor;
```

## 3. 核心函数

> **统一格式**：`[返回类型] 函数名(...)` — 所属头文件

---

### 3.1 添加医生

```c
// doctor.h
void addDoctor(Doctor* head, Doctor* tail,
    char name[], char dept[], char schedule[], int maxPatients);
```

**实现思路**：
1. **第1步**：`malloc(sizeof(Doctor))` 分配节点
2. **第2步**：调用 `generateUniqueId("DOC", id)` 生成工号前缀
3. **第3步**：填充 `node->data.name`、`node->data.dept`、`node->data.schedule`、`node->data.maxPatients`
4. **第4步**：`node->data.currentPatients = 0`（今日接诊数从0开始）
5. **第5步**：尾插法插入链表（参考数据结构章节）
6. **第6步**：调用 `rebuildDoctorFile(...)` 保存到文件

---

### 3.2 删除医生

```c
// doctor.h
void delDoctor(Doctor* head, Doctor* tail, Doctor* d);
```

**实现思路**：与病人模块删除函数完全一致，参考数据结构章节。
1. **第1步**：边界检查
2. **第2步**：分四种情况处理（唯一节点/头/尾/中间）
3. **第3步**：更新指针，释放内存

---

### 3.3 修改医生信息

```c
// doctor.h
void modifyDoctor(Doctor* d, char schedule[], int maxPatients);
```

**实现思路**：
1. **第1步**：边界检查（d==NULL 直接返回）
2. **第2步**：调用 `safeStringCopy(d->data.schedule, schedule, 100)` 复制出诊时间
3. **第3步**：`d->data.maxPatients = maxPatients`
4. **第4步**：调用 `rebuildDoctorFile(...)` 保存

---

### 3.4 查询医生

```c
// doctor.h
Doctor* findDoctorByEmpNo(Doctor* head, char* empNo);           // 按工号精确查找
Doctor* findDoctorByName(Doctor* head, char* name);             // 按姓名查找
Doctor* findDoctorsByDept(Doctor* head, char* dept);            // 按科室查找（返回第一个匹配）
```

**实现思路**：
1. **第1步**：`Doctor* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历链表
3. **第3步**：`strcmp(cur->data.empNo, empNo) == 0` 等条件比对
4. **第4步**：找到则返回 `cur`，遍历完返回 `NULL`

---

### 3.5 医生接诊检查

```c
// doctor.h
int canAcceptPatient(Doctor d);              // 医生是否还能接诊（1=能, 0=不能）
void incrementPatientCount(Doctor d);        // 挂号成功后接诊数+1
```

**实现思路**：
1. **canAcceptPatient**：比较 `d.data.currentPatients < d.data.maxPatients`，小于则返回 1，否则返回 0
2. **incrementPatientCount**：检查还有名额后，`d.data.currentPatients++`

---

### 3.6 重置每日接诊计数

```c
// doctor.h
void resetDailyPatients(Doctor head);
```

**实现思路**：
1. **第1步**：`Doctor* cur = head`
2. **第2步**：`while(cur != NULL)` 遍历所有医生
3. **第3步**：`cur->data.currentPatients = 0`
4. **第4步**：`cur = cur->next`
5. **第5步**：挂号系统每天开始时应调用此函数

---

### 3.7 科室统计

```c
// doctor.h
void getDeptStats(Doctor head, char* dept, int* count);
```

**实现思路**：
1. **第1步**：`Doctor* cur = head; *count = 0`
2. **第2步**：`while(cur != NULL)` 遍历链表
3. **第3步**：`strcmp(cur->data.dept, dept) == 0` → `(*count)++`
4. **第4步**：`cur = cur->next`

---

### 3.8 列表显示

```c
// doctor.h
void listAllDoctors(Doctor* head);
```

**实现思路**：从头遍历链表，逐个 `printf` 打印各字段（工号、姓名、科室、出诊时间、最大接诊数、已接诊数）。

---

### 3.9 文件读写

```c
// doctor.h
void buildDoctorChain(Doctor* head, Doctor* tail);   // 从文件加载医生列表
void rebuildDoctorFile(Doctor* head);                 // 保存医生列表到文件
void freeDoctorChain(Doctor* head);                   // 释放医生链表内存
```
