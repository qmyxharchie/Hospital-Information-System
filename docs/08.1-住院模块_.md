# 住院模块 - 学习版

> 本文档为学习版，代码部分已替换为函数名和实现思路提示。
> 结构体采用 Data + Node 分离模式，每个函数标注返回类型和头文件来源。

---

## 1. 模块概述

### 1.1 功能描述

**住院管理**：入院登记（自动分配床位）、出院结算（计算费用、释放床位）、住院状态跟踪。

### 1.2 核心亮点

**自动床位分配**：入院时自动分配空闲床位，出院时自动释放床位，减少人工操作。

## 3. 核心函数

> **统一格式**：`[返回类型] 函数名(...)` — 所属头文件

---

### 3.1 入院登记

```c
// hospitalization.h
void addHospitalization(HospitalizationNode** head, HospitalizationNode** tail, ...);
```

**实现思路**：
1. **第1步**：先调用 `allocateBed` 分配床位，如果返回 NULL 则入院失败，提示"床位不足"
2. **第2步**：`malloc(sizeof(HospitalizationNode))` 分配节点
3. **第3步**：调用 `generateUniqueId("HOS", id)` 生成住院单号，加"HOS"前缀
4. **第4步**：填充各字段（bedNo 用分配结果，prepay 用传入参数，totalCost=0）
5. **第5步**：调用 `getCurrentTime` 获取入院日期，填充 admissionDate
6. **第6步**：`strcpy(status, "在院")`
7. **第7步**：尾插法插入链表
8. **第8步**：调用 `rebuildHospitalizationFile(*head)` 保存

---

### 3.2 出院结算

```c
// hospitalization.h
void dischargePatient(HospitalizationNode* h, double totalCost);
```

**实现思路**：
1. **第1步**：边界检查（h==NULL 直接返回）
2. **第2步**：`h->data.totalCost = totalCost` 填入总费用
3. **第3步**：`strcpy(h->data.status, "已出院")` 标记出院
4. **第4步**：计算应退金额 = `prepay - totalCost`
5. **第5步**：打印结算单（住院单号、姓名、入院日期、总费用、预交金额、退款金额）
6. **第6步（关键）**：调用 `findBedByNo(g_bedHead, h->data.bedNo)` 找到对应床位，然后调用 `freeBed` 释放床位

---

### 3.3 查询函数

```c
// hospitalization.h
HospitalizationNode* findHospitalizationByCardNo(HospitalizationNode* head, char* cardNo);  // 按病人卡号查住院记录
HospitalizationNode* findHospitalizationByNo(HospitalizationNode* head, char* recordNo);    // 按住院单号查住院记录
HospitalizationNode* findCurrentHospitalizations(HospitalizationNode* head);                  // 查找当前在院病人
```

**实现思路**：遍历链表，用 `strcmp` 匹配对应字段，找到返回节点指针，未找到返回 NULL。

### 3.4 列表显示

void listAllHospitalizations(HospitalizationNode* head);  // 所有住院记录列表

**实现思路**：从头遍历链表，逐个 `printf` 打印各字段。
