# 医院综合信息管理系统 - 小组复刻计划书

> **课程**：程序设计基础课程设计

> **预计工期**：2-3周  
> **小组成员**：3-5人

---

## 一、项目概述

### 1.1 项目目标

复刻并理解一个完整的医院信息管理系统，掌握以下技能：
- C语言/C++基础编程
- 双向链表数据结构
- 文件IO操作
- GUI图形界面开发
- CMake项目构建
- 团队协作开发

### 1.2 项目功能

实现一个小型医院的六大核心模块：
1. 病人信息管理（增删改查）
2. 医生信息管理（增删改查）
3. 挂号记录管理（挂号、取消、完成）
4. 药品信息管理（增删改查、库存预警）
5. 住院记录管理（入院、出院结算）
6. 床位信息管理（分配、释放）

## 七、常见问题

### Q1: 编译报错怎么办？

**解决步骤**：
1. 仔细阅读错误信息
2. 定位到报错行
3. 检查括号、分号是否匹配
4. 检查头文件是否正确包含
5. 搜索引擎搜索错误信息

### Q2: 链表操作出错怎么办？

**解决步骤**：
1. 检查指针初始化
2. 检查malloc是否成功
3. 检查链表边界（头、尾、中间）
4. 检查free后是否置NULL
5. 使用printf调试

### Q3: 文件读写失败怎么办？

**解决步骤**：
1. 检查文件路径是否正确
2. 检查目录是否存在
3. 检查文件权限
4. 检查文件格式是否匹配
5. fopen的mode参数是否正确

### Q4: 界面显示异常怎么办？

**解决步骤**：
1. 检查坐标和尺寸是否正确
2. 检查控件是否添加到父容器
3. 检查是否调用了draw()
4. 检查事件绑定是否正确
