## 2. Visual Studio 安装

### 2.1 下载

1. 访问：https://visualstudio.microsoft.com/downloads/
2. 下载 **Visual Studio Community 2022**（免费）

### 2.2 安装步骤

**Step 1**: 运行安装程序

**Step 2**: 选择"使用C++的桌面开发"

需要勾选的工作负载：
- ✅ **使用C++的桌面开发**
- ✅ Windows 11 SDK（如果有）

需要勾选的单组件：
- ✅ MSVC v143 - VS 2022 C++ x64/x86 生成工具
- ✅ Windows SDK（10.0.22621.0或更新版本）

**Step 3**: 安装位置

建议安装到默认位置，或空间充足的其他盘符。

**Step 4**: 等待安装完成

安装时间取决于网络速度，通常10-30分钟。

### 2.3 验证安装

1. 打开Visual Studio
2. 创建新项目 → C++ → Windows Console Application
3. 编写测试代码：

```cpp
#include <iostream>
int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

4. 按 `Ctrl+F5` 运行
5. 如果看到输出，说明安装成功

## 3. EasyX 图形库安装

### 3.1 下载EasyX

1. 访问官网：https://easyx.cn/
2. 点击"下载EasyX"
3. 下载最新版本（通常文件名如 `easyx_20220606.exe`）

### 3.2 安装步骤

**Step 1**: 运行EasyX安装程序

**Step 2**: 选择Visual Studio版本

程序会自动检测已安装的VS版本，选择对应的选项：
- Visual Studio 2022
- Visual Studio 2019
- Visual Studio 2017
- ...

**Step 3**: 确认安装

点击"安装"按钮，等待安装完成。

### 3.3 验证安装

创建一个新项目，添加以下代码：

```cpp
#include <graphics.h>
#include <conio.h>

int main() {
    // 初始化图形窗口 640x480
    initgraph(640, 480);
    
    // 画一个圆
    circle(320, 240, 100);
    
    // 按任意键继续
    _getch();
    
    // 关闭图形窗口
    closegraph();
    
    return 0;
}
```

**编译方式**：
- 确保项目配置为 **x86（32位）** 或 **x64（64位）**
- 包含头文件：`#include <graphics.h>`
- 链接库：`#pragma comment(lib, "graphics.lib")`

**运行结果**：应该出现一个640x480的黑色窗口，中间有一个圆。

## 4. CMake 安装（可选）

### 4.1 下载CMake

1. 访问：https://cmake.org/download/
2. 下载 Windows x64 Installer：`cmake-3.x.x-windows-x86_64.msi`

### 4.2 安装步骤

1. 运行安装程序
2. 选择 "Add CMake to the system PATH for all users"
3. 完成安装

### 4.3 验证安装

打开PowerShell，运行：

```powershell
cmake --version
```

应该显示CMake版本信息。

## 5. Git 安装（可选）

### 5.1 下载Git

1. 访问：https://git-scm.com/download/win

### 5.2 安装步骤

   - ✅ Git Bash Here
   - ✅ Git GUI Here
   - ✅ Use Visual Studio Code as Git's default editor

### 5.3 验证安装

打开PowerShell，运行：

```powershell
git --version
```

## 6. 项目路径配置

### 6.1 路径要求

**推荐路径**（英文，无空格）：
```
D:\hospital-management
```

**不推荐路径**：
```
D:\我的项目\hospital-management  ❌ 中文
C:\Program Files\hospital        ❌ 空格
桌面\hospital                    ❌ 特殊位置
```

### 6.2 创建项目目录

```powershell
# 在D盘创建项目文件夹
mkdir D:\hospital-management

# 创建子目录
cd D:\hospital-management
mkdir include
mkdir src
mkdir data
mkdir backup
mkdir bin
mkdir docs
mkdir image
```

## 7. 编译测试

### 7.1 创建测试项目

1. 打开Visual Studio
2. 文件 → 新建 → 项目
3. 选择"空项目"
4. 项目名称：`HospitalManagement`
5. 位置：`D:\hospital-management`

### 7.2 配置项目

**Step 1**: 添加源文件

1. 右键"源文件" → 添加 → 新建项
2. 选择C++文件，命名`test.cpp`

**Step 2**: 配置项目属性

1. 右键项目 → 属性
2. 配置属性 → C/C++ → 预处理器 → 预处理器定义
   - 添加：`_CRT_SECURE_NO_WARNINGS`
3. 配置属性 → 链接器 → 系统 → 子系统
   - 选择：控制台 (/SUBSYSTEM:CONSOLE)

### 7.3 编译运行

按 `Ctrl+F5` 编译运行。

## 8. 常见问题

### Q1: Visual Studio没有C++选项？

**解决**：
1. 重新运行VS Installer
2. 修改 → 更多 → 修改工作负载
3. 确保勾选"使用C++的桌面开发"

### Q2: EasyX安装后编译报错？

**解决**：
1. 确认EasyX版本与VS版本匹配
2. 项目配置改为x86或x64
3. 包含正确头文件：`#include <graphics.h>`

### Q3: 找不到graphics.h？

**解决**：
1. 重新安装EasyX
2. 检查项目平台（x86/x64）是否正确
3. 确认头文件目录配置正确

### Q4: CMake找不到编译器？

**解决**：
1. 打开x64 Native Tools Command Prompt for VS 2022
2. 在该命令行中运行cmake
