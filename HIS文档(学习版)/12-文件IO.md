## 1. 文件存储概述

### 1.1 为什么用文本文件？

- 简单易用，无需数据库
- 便于调试和查看数据
- 适合小型项目
- 无需额外安装软件

### 1.2 数据目录定义

在 `file_io.h` 中用宏定义文件路径：

**提示**：
```c
#define DATA_DIR "data/"
#define BACKUP_DIR "backup/"

#define PATIENT_FILE    DATA_DIR "patient.txt"
#define DOCTOR_FILE     DATA_DIR "doctor.txt"
// ... 其他文件路径同理
```

## 2. 文件格式设计

每个数据文件的通用格式：

**提示**：
- `1` + 各字段值 → 一条有效记录
- `-1` → 文件结束标记
- 每条记录之间留空行

## 3. 读取文件（从文件加载到链表）

**函数名**：`buildPatientChain(Patient** head, Patient** tail)`
**函数名**：`buildDoctorChain(Doctor** head, Doctor** tail)`
（其他模块同理）

**实现思路（以病人为例）**：
1. `fopen(PATIENT_FILE, "r")` 打开文件
2. **文件不存在时**：用 `fopen(PATIENT_FILE, "w")` 创建空文件，写入"-1"，关闭并返回
3. 定义 `Patient* pre = NULL` 跟踪上一个节点
4. **主循环**（while 1）：
   - `fscanf(fp, "%d", &opt)` 读入标记
   - `opt == -1` → break 跳出循环
   - `opt == 1` → 说明是一条有效记录：
     - `malloc(sizeof(Patient))` 分配节点
     - 初始化 next=pre=NULL
     - `fscanf(fp, "%s", node->cardNo)` 依次读入所有字段
     - 尾插法：第一个节点 *head=now，后续节点 pre->next=now, now->pre=pre
     - `pre = now` 更新 pre
5. 循环结束后，`*tail = pre`
6. `fclose(fp)` 关闭文件

---

## 4. 写入文件（从链表保存到文件）

**函数名**：`rebuildPatientFile(Patient* head)`
**函数名**：`rebuildDoctorFile(Doctor* head)`

**实现思路（以病人为例）**：
1. `fopen(PATIENT_FILE, "w")` 以写入模式打开（会清空原文件）
2. `Patient* p = head`
3. **主循环**（while p != NULL）：
   - `fprintf(fp, "1\n")` 写有效标记
   - `fprintf(fp, "%s\n", p->cardNo)` 依次写入所有字段
   - `fprintf(fp, "\n")` 每条记录后写空行
   - `p = p->next` 推进
4. **循环结束后**：`fprintf(fp, "-1\n")` 写结束标记
5. `fclose(fp)` 关闭文件

---

## 5. 数据备份

**函数名**：`backupAllData()`

**实现思路**：
1. 用 `getCurrentTimeForFile()` 获取时间字符串（用于文件名，避免覆盖）
2. 对每个数据文件执行：拼接备份文件路径（如 `backup/patient_20260407.txt`）
3. 调用 `copyFile(sourcePath, backupPath)` 复制文件

**提示**：`copyFile` 函数思路：
- 以二进制模式打开源文件和目标文件
- 循环读取并写入，直到 EOF

---

## 6. 注意事项

1. **每次修改数据后都要调用 rebuildXxxFile**，否则退出程序后数据会丢失
2. 程序启动时调用所有 `buildXxxChain`，加载上次保存的数据
3. 备份文件放在 `backup/` 目录，不要和 `data/` 混在一起
