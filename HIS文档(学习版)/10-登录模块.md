## 1. 模块概述

### 1.1 功能描述

登录模块负责用户身份验证：
- 用户登录
- 管理员登录
- 用户注册
- 密码加密存储

### 1.2 安全特性

**MD5密码加密**：密码不以明文存储，相同密码产生相同哈希值，不可逆向解密。

## 2. 数据结构

在 `login.h` 中定义：

**提示1**：User 结构体，包含：
- username[50] — 用户名
- password[100] — 密码（MD5哈希值，不是明文）
- role — 角色（0=普通用户，1=管理员）
- lastLogin[30] — 最后登录时间
- next / pre — 双向链表指针

**提示2**：LoginStatus 枚举类型，包含：
- LOGIN_FAILED — 登录失败
- LOGIN_SUCCESS_USER — 普通用户登录成功
- LOGIN_SUCCESS_ADMIN — 管理员登录成功
- LOGIN_EXIT — 退出系统

## 3. MD5加密

### 3.1 基本原理

**提示**：MD5 把任意长度的字符串转换为一个 128 位的哈希值（32位十六进制字符串）。相同输入一定产生相同输出，无法反推原始密码。

**本项目的使用方式**：只需要会**调用**，不需要手写算法。项目中已提供 `md5Hash(password, outputHash)` 函数，调用方式如下：

```c
char hashed[100];
md5Hash(password, hashed);  // 输入密码，输出哈希值存到 hashed 里
```

### 3.2 常用密码的MD5参考

|--------|----------|

| 123456 | e10adc3949ba59abbe56e057f20f883e |

## 4. 核心函数

### 4.1 用户登录

**函数名**：`login(char username[], char password[])`

**实现思路**：
1. 调用 `buildUserChain` 加载所有用户
2. 调用 `md5Hash(password, pwdHash)` 生成密码哈希
3. 遍历用户链表，匹配 username 和 passwordHash
4. 匹配成功 → 记录当前登录用户和角色，关闭文件，返回对应状态
5. 遍历完没找到 → 返回 LOGIN_FAILED

### 4.2 用户注册

**函数名**：`registerUser(char username[], char password[], int role)`

**实现思路**：
1. 调用 `buildUserChain` 加载现有用户
2. 检查用户名是否已存在（遍历链表比对）
3. 如果已存在，打印错误，返回 false
4. 如果不存在：malloc 新节点，填充各字段，调用 `md5Hash` 加密密码
5. 尾插法插入链表
6. 调用 `rebuildUserFile` 保存到文件
7. 释放链表内存，打印注册成功

### 4.3 文件读写

**函数名**：`buildUserChain(User** head, User** tail)`
**函数名**：`rebuildUserFile(User* head)`
