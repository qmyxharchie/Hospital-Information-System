## 1. 链表基础概念

### 1.1 什么是链表？

链表是一种线性数据结构，由一系列节点组成，每个节点包含数据和指向下一个节点的指针。

**提示**：想象成一列火车，每节车厢（节点）里有数据，车厢之间用钩子（指针）连接。

### 1.2 为什么用链表？

| 特性 | 数组 | 链表 |
|------|------|------|
| 大小 | 固定 | 可动态变化 |
| 插入 | 需要移动元素 | 只需修改指针 |
| 删除 | 需要移动元素 | 只需修改指针 |
| 访问 | O(1)随机访问 | O(n)遍历 |
| 内存 | 连续 | 不连续 |

**本项目选择链表的原因**：数据量不确定、插入删除频繁、实现相对简单。

---

## 2. 单向链表 vs 双向链表

### 2.1 单向链表

每个节点只有一个 next 指针，只能向后遍历。

### 2.2 双向链表

每个节点有两个指针：next（指向后一个）和 pre（指向前一个），可以双向遍历。

**提示**：双向链表比单向多一个 pre 指针。删除节点时更方便，不需要额外记住前一个节点。

## 4. 链表操作详解

### 4.1 初始化链表

**提示**：函数名 `initPatientChain`
- 接收两个二级指针：head 和 tail
- 将两者都初始化为 NULL

### 4.2 添加节点（尾插法）

**提示**：函数名 `addPatient`
- 步骤：① malloc 分配内存 ② 填充各字段 ③ 初始化 next=pre=NULL ④ 生成唯一ID（调用工具函数） ⑤ 插入链表尾部
- 如果链表为空，新节点既是头也是尾
- 如果不为空，更新 tail 和前一个节点的 next 指针

### 4.3 查找节点

**提示**：函数名 `findPatientByCardNo` / `findPatientByName`
- 遍历链表，逐个比较目标字段
- 找到返回节点指针，未找到返回 NULL

### 4.4 删除节点

**提示**：函数名 `delPatient`
- 分四种情况处理：
  - 情况1：链表只有一个节点（head==tail）
  - 情况2：删除头节点（p==head）
  - 情况3：删除尾节点（p==tail）
  - 情况4：删除中间节点
- 删除后记得 free(p)

### 4.5 遍历链表

**提示**：函数名 `listAllPatients`
- 从 head 出发，while(p!=NULL) 逐个访问并打印
- 用 p = p->next 推进

### 4.6 释放链表内存

**提示**：函数名 `freePatientChain`
- while 循环逐个 free，记得用临时变量保存 next 指针

## 5. 链表API总结

| 函数名（按此命名） | 说明 |
|------|------|
| `initXxxChain` | 初始化空链表（传入 head 和 tail 的地址） |
| `addXxx` | 尾部添加节点 |
| `delXxx` | 删除指定节点 |
| `findXxxByCardNo` | 按卡号/工号等唯一ID查找 |
| `findXxxByName` | 按姓名查找 |
| `modifyXxx` | 修改指定节点信息 |
| `listAllXxx` | 遍历显示所有节点 |
| `freeXxxChain` | 释放所有节点内存 |

## 6. 常见问题

**Q1: 链表和数组哪个好？**
数据量固定+随机访问用数组；数据量变化大+频繁增删用链表。

**Q2: 为什么要保存 head 和 tail 两个指针？**
head 用于遍历，tail 用于 O(1) 尾插。

**Q3: 什么是野指针？**
未初始化或已释放未置 NULL 的指针，会导致程序崩溃。养成习惯：malloc 后立即初始化，free 后立即置 NULL。
