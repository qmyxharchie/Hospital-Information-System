## 1. 模块概述

### 1.1 功能描述

挂号模块负责管理病人的挂号记录：
- 病人挂号（自动检查医生名额）
- 取消挂号
- 完成就诊
- 时间范围查询

### 1.2 业务规则

1. 病人必须存在（应先添加病人）
2. 医生必须有剩余名额（currentPatients < maxPatients）
3. 同一医生同时只能有一个"待就诊"状态的挂号

---

## 2. 数据结构

在 `registration.h` 中定义 Registration 结构体：

**提示**：包含字段：
- regNo[20] — 挂号单号
- patientCardNo[20] — 病人卡号
- patientName[50] — 病人姓名
- doctorEmpNo[20] — 医生工号
- doctorName[50] — 医生姓名
- dept[50] — 科室
- date[20] — 挂号日期
- status[20] — 状态（待就诊/已完成/已取消）
- next / pre — 双向链表指针

## 3. 核心函数

### 3.1 挂号（最核心的函数）

**函数名**：`addRegistration(Registration** head, Registration** tail, ...)`

**实现思路（关键！涉及跨模块调用）**：
1. **第1步**：验证医生是否存在，调用 `findDoctorByEmpNo(g_doctorHead, doctorEmpNo)`，找不到则报错返回
2. **第2步**：检查医生是否还有名额，如果 `currentPatients >= maxPatients`，报错返回
3. **第3步**：malloc 分配 Registration 节点
4. **第4步**：用 generateUniqueId() 生成挂号单号（加 "REG" 前缀），填充所有字段
5. **第5步**：尾插法插入链表
6. **第6步（重要）**：调用 `incrementPatientCount(d)`，将医生的 currentPatients++，因为挂了一个号占了一个名额
7. 打印挂号成功信息，返回1

**⚠️ 注意**：函数内部需要能访问到 `g_doctorHead`（医生链表头指针）。这是模块间数据共享的例子。

### 3.2 取消挂号

**函数名**：`cancelRegistration(Registration** head, Registration** tail, Registration* r)`

**实现思路**：
1. 检查 r != NULL
2. **不能取消已完成的就诊**：如果 status == "已完成"，报错返回
3. 取消时需要把医生的接诊数减回来：调用 `findDoctorByEmpNo`，然后 currentPatients--
4. 将 status 改为"已取消"
5. 打印取消成功信息

### 3.3 完成就诊

**函数名**：`completeRegistration(Registration* r)`

**实现思路**：
1. 检查 r != NULL
2. 只有"待就诊"状态才能完成，不是则报错
3. 将 status 改为"已完成"
4. 注意：完成就诊**不需要**减医生接诊数，因为名额是在挂号时占用的，就诊只是标记为完成

### 3.4 查询

**函数名**：
- `findRegistrationByNo(Registration* head, char* regNo)` — 按挂号单号查
- `findRegistrationByPatient(Registration* head, char* patientCardNo)` — 按病人卡号查
- `listRegistrationsByDoctor(Registration* head, char* doctorEmpNo)` — 按医生查
- `listRegistrationsByStatus(Registration* head, char* status)` — 按状态查

### 3.5 列表显示

**函数名**：`listAllRegistrations(Registration* head)`

### 3.6 文件读写

**函数名**：`buildRegistrationChain`、`rebuildRegistrationFile`
