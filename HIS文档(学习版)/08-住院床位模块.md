# 住院与床位模块 - 学习版

> 本文档为学习版，代码部分已替换为函数名和实现思路提示。

---

## 1. 模块概述

### 1.1 功能描述

**住院管理**：入院登记（自动分配床位）、出院结算（计算费用、释放床位）、住院状态跟踪。

**床位管理**：床位增删改查、病区管理、床位状态跟踪。

### 1.2 核心亮点

**自动床位分配**：入院时自动分配空闲床位，出院时自动释放床位，减少人工操作。

---

## 2. 数据结构

### 2.1 住院记录结构体

**提示**：在 `hospitalization.h` 中定义 `Hospitalization` 结构体，包含：
- recordNo[20] — 住院单号
- patientCardNo[20] — 病人卡号
- patientName[50] — 病人姓名
- bedNo[20] — 床位号
- prepay — 预交金额（double）
- totalCost — 总费用（double）
- admissionDate[20] — 入院日期
- status[20] — 状态（在院/已出院）
- next / pre — 双向链表指针

### 2.2 床位结构体

**提示**：在 `bed.h` 中定义 `Bed` 结构体，包含：
- ward[30] — 病区
- bedNo[20] — 床位号
- patientCardNo[20] — 病人卡号（空=无病人）
- patientName[50] — 病人姓名
- status[20] — 状态（空闲/占用/维修）
- next / pre — 双向链表指针

## 3. 核心函数

### 3.1 自动分配床位

**函数名**：`allocateBed(Bed* head, char* patientCardNo, char* patientName)`

**实现思路**：
1. 从 head 遍历整个床位链表
2. 找到第一个 status == "空闲" 的床位
3. 找到后：strcpy 填入病人信息，将 status 改为"占用"
4. 打印分配成功信息，返回床位号
5. 遍历完没有空闲床位，打印"暂无空闲床位"，返回 NULL

### 3.2 释放床位

**函数名**：`freeBed(Bed* b)`

**实现思路**：
1. 检查 b != NULL
2. 将 patientCardNo 和 patientName 设为"空"，status 设为"空闲"
3. 打印释放成功信息

### 3.3 入院登记

**函数名**：`addHospitalization(Hospitalization** head, Hospitalization** tail, ...)`

**实现思路**：
1. 先调用 `allocateBed` 分配床位，如果分配失败则入院失败
2. malloc 分配 Hospitalization 节点
3. 用 generateUniqueId() 生成住院单号（加 "HOS" 前缀）
4. 填充各字段（bedNo 用分配结果，prepay 用传入参数，totalCost=0，status="在院"）
5. 用 getCurrentTime 获取入院时间
6. 尾插法插入链表
7. 调用 `rebuildHospitalizationFile` 保存

### 3.4 出院结算

**函数名**：`dischargePatient(Hospitalization* h, double totalCost)`

**实现思路**：
1. 检查 h != NULL
2. 更新 totalCost 和 status="已出院"
3. 计算应退金额 = prepay - totalCost
4. 打印结算单（住院单号、姓名、入院日期、总费用、预交金额、退款金额）
5. 返回退款金额

**关键**：出院后还需调用 `freeBed` 释放床位。

### 3.5 查询与列表

**函数名**：
- `findHospitalizationByCardNo(Hospitalization* head, char* cardNo)`
- `listAllHospitalizations(Hospitalization* head)`
- `listAllBeds(Bed* head)`
- `listBedsByWard(Bed* head, char* ward)`

### 3.6 文件读写

**函数名**：`buildHospitalizationChain`、`rebuildHospitalizationFile`、`buildBedChain`、`rebuildBedFile`

## 4. 文件格式（参考）

```

HOS20260407150000    ← 住院单号
PT001                ← 病人卡号
张三                 ← 病人姓名
B101                 ← 床位号
5000.00              ← 预交金额
0                    ← 总费用
2026-04-07          ← 入院日期
在院                 ← 状态
-1

B101                  ← 床位号

占用                  ← 状态
-1
```
