## 2. Visual Studio 安装

### 2.1 下载

访问 https://visualstudio.microsoft.com/downloads/ 下载 **Visual Studio Community 2022**（免费）

### 2.2 安装步骤

**Step 1**: 运行安装程序

**Step 2**: 选择工作负载 → 勾选 **"使用C++的桌面开发"**

需要勾选的单组件：
- MSVC v143 - VS 2022 C++ x64/x86 生成工具
- Windows SDK

**Step 3**: 安装位置建议默认或空间充足的盘符，等待安装完成（通常10~30分钟）

### 2.3 验证安装

打开VS → 新建项目 → C++ → Windows Console Application，编译运行一个简单的 main 函数，观察输出是否正常。

---

## 3. EasyX 图形库安装

### 3.1 下载

访问 https://easyx.cn/ 下载最新版本

### 3.2 安装步骤

1. 运行 EasyX 安装程序
2. 程序自动检测 VS 版本，选择对应版本（VS 2022）
3. 点击"安装"等待完成

### 3.3 验证安装

**提示**：创建一个新项目，尝试以下步骤：
1. 包含头文件 `#include <graphics.h>` 和 `#include <conio.h>`
2. 初始化图形窗口（提示：参考 EasyX 官方文档的 `initgraph` 函数）
3. 绘制一个圆形（提示：参考 `circle` 函数）
4. 设置平台为 x86 或 x64
5. 编译运行，观察是否出现图形窗口

**预期结果**：640x480 黑色窗口，中间有圆。

## 4. CMake 安装（可选）

### 4.1 下载安装

### 4.2 验证安装

PowerShell 中运行 `cmake --version`，观察是否输出版本号。

## 6. 项目路径配置

### 6.1 路径要求

**推荐**：纯英文路径，无空格，无中文
```
D:\hospital-management    ✅
```

**不推荐**：
```
D:\我的项目\hospital    ❌ 中文
C:\Program Files\hos    ❌ 空格
桌面\hospital            ❌ 特殊位置
```

### 6.2 创建项目目录

**提示**：在命令行或 PowerShell 中依次执行以下操作：
1. 进入目标盘符（如 D:）
2. 创建项目根目录 `hospital-management`
3. 在根目录下依次创建子目录：`include`、`src`、`data`、`backup`、`bin`、`docs`、`image`
4. 如果使用 StellarX，还需要在 include 和 src 下各创建一个 `StellarX` 子目录

## 7. 编译测试

### 7.1 创建测试项目

1. 打开 Visual Studio → 文件 → 新建 → 项目 → 空项目
2. 名称设为 `HospitalManagement`，位置设为项目根目录

### 7.2 配置项目属性

**提示**：右键项目 → 属性，进行以下配置：
- **预处理器定义**：添加 `_CRT_SECURE_NO_WARNINGS`（消除安全警告）
- **子系统**：选择 `控制台 (/SUBSYSTEM:CONSOLE)`
- **平台**：确保为 x86 或 x64，与 EasyX 匹配

### 7.3 编译运行

按 `Ctrl+F5` 编译运行，观察控制台输出。

## 8. 常见问题

**Q1: VS 没有 C++ 选项？**
重新运行 VS Installer → 修改 → 确保勾选"使用C++的桌面开发"

**Q2: EasyX 安装后编译报错？**
确认 EasyX 版本与 VS 版本匹配；项目平台改为 x86 或 x64；包含头文件正确。

**Q3: 找不到 graphics.h？**
重新安装 EasyX；检查项目平台（x86/x64）；确认头文件目录配置正确。

**Q4: CMake 找不到编译器？**
在 "x64 Native Tools Command Prompt for VS 2022" 中运行 cmake。
